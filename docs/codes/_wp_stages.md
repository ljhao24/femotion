## 20 收缩徐变的结构效应和施工阶段分析（4.3.8、4.3.9、6.5.6、附录 C，p17、p67、p126–129；条文说明 p163–165、p204、p249–251）

程序：`femotion.codes.jtg.creep`（条文说明的闭合式、附录 C 的数组形式、后期预应力损失）和 `femotion.frame.stages`（通用模块，非规范专用：
施工阶段、体系转换、逐步法收缩徐变）。例子 `examples/jtg_staged_girder.py`（先简支后连续的三跨后张法梁，算到成桥后 10 年）。

### 20.1 条文（4.3.8、4.3.9，p17；条文说明 p163、p165）

4.3.8：连续梁等超静定结构要视情况计入温度、混凝土收缩徐变、基础不均匀沉降；预应力混凝土超静定结构还要计入预加力次效应（见第 6.1 节）。
条文说明（p163）：徐变对上述各项作用一般起卸载作用，可在有明确规定或可靠方法（如预应力损失、体系转换）时计入。

4.3.9：计算徐变时可假定徐变与混凝土应力成线性关系；缺少符合当地条件的资料和方法时，徐变系数、收缩应变按附录 C 取（第 6.6 节）。
条文说明（p165）：压应力为 0.3～0.6 倍立方体强度时可按线性考虑，一般压应力不超过立方体强度的一半。

程序约定：线性徐变（应力与徐变成正比、叠加原理成立），不检查应力水平；应力超过约 0.5 fcu 时线性假定不再可靠，由使用者判断。

### 20.2 不转换体系的连续梁（条文说明式 4-7，p163）

施工中不转换体系的预应力连续梁，计入松弛、收缩、徐变损失后的总次效应 = 张拉时（第一批损失后）的弹性次效应 × 平均有效系数：

$$C = P_e / P_i \qquad (4\text{-}7)$$

Pe：全部损失完成后预应力钢筋的平均张拉力；Pi：瞬时（第一批）损失完成后的平均张拉力。

程序：`jtg.creep.average_effective_factor(Pe, Pi, weights=None)` → C；`long_term_secondary(S, Pe, Pi, weights=None)` → C × S（S 为张拉时的
弹性次效应，任意效应数组：弯矩、剪力、支反力）。
- 程序约定：Pe、Pi 给成沿钢束各单元的力时，按 `weights`（如单元长度）加权平均，未给时等权。
- 与逐步法的关系（`tests/test_stages.py`）：徐变均匀（各单元同一龄期、同一徐变系数）且约束不变时，按线性徐变理论的第一定理，徐变不改变荷载
  产生的内力，式（4-7）与逐步法完全一致（差 10⁻⁹）。不一致的来源：一是徐变不均匀，算例（两跨 2 × 20 m、钢束第一跨直线、第二跨抛物线）中
  第一跨比第二跨早浇 53 天，跨中支点次弯矩逐步法比 C × 弹性值大 0.9%；二是损失沿钢束不均匀，C 取平均值，同一算例中损失从一端 0.4 倍
  线性增到另一端 1.6 倍时差 −0.5%，而逐步法与按各单元实际有效力的弹性计算（`femotion.frame.prestress`，第 6.1 节的做法）完全一致。

### 20.3 体系转换后的徐变次效应（条文说明式 4-8～4-20，p163–165）

条文说明的简化方法，前提：（1）简支梁或悬臂梁的浇筑、预制、架设和转换为连续梁都在同一时刻 τ 完成，此后徐变受多余约束限制；
（2）先期结构在自重下的弯矩为 M1g，同一自重若作用在后期结构上为 M2g；转换后 M1g 随时间逐渐趋向 M2g，t 时为 Mgt。

在后期结构上设铰作基本结构（图 4-10），铰处未知力 Mgt。dt 内的变形协调：

$$dM_{gt}\cdot\delta + M_{gt}\cdot\delta\cdot d\phi_t + \Delta_g\cdot d\phi_t = 0 \qquad (4\text{-}8)$$

$$\frac{dM_{gt}}{d\phi_t} + M_{gt} = -\frac{\Delta_g}{\delta} = M_{2g} \qquad (4\text{-}9)$$

Δg：基本结构在自重下铰处的弹性转角；δ：铰处单位弯矩引起的弹性转角。解为

$$M_{gt} = e^{-\phi_t}\left(M_{2g}\cdot e^{\phi_t} + c\right) \qquad (4\text{-}10)$$

由 t = τ 时 Mgt = M1g 得 c = −(M2g − M1g)e^{φτ}，代回：

$$M_{gt} = e^{-\phi_t}\left[M_{2g}\cdot e^{\phi_t} - (M_{2g} - M_{1g})\cdot e^{\phi_\tau}\right] = M_{2g} - (M_{2g} - M_{1g})\cdot e^{-\phi(t,\tau)} \qquad (4\text{-}11)$$

$$M_{gt} = M_{1g} + (M_{2g} - M_{1g})\cdot\left(1 - e^{-\phi(t,\tau)}\right) \qquad (4\text{-}12)$$

（3）预加力引起的弯矩重分配同样计算，用 t 时有效预加力的弯矩代替自重弯矩，M1pt 代 M1g、M2pt 代 M2g：

$$M_{pt} = M_{1pt} + (M_{2pt} - M_{1pt})\cdot\left[1 - e^{-\phi(t,\tau)}\right] \qquad (4\text{-}13)$$

$$M_{2pt} = M^0_{2pt} + M'_{2pt} \qquad (4\text{-}14)$$

$$M_{1pt} = M^0_{1pt} + M'_{1pt} \qquad (4\text{-}15)$$

$$M^0_{2pt} = M^0_{1pt} \qquad (4\text{-}16)$$

$$M_{pt} = M_{1pt} + (M'_{2pt} - M'_{1pt})\cdot\left[1 - e^{-\phi(t,\tau)}\right] \qquad (4\text{-}17)$$

先期结构静定时 M′1pt = 0：

$$M_{pt} = M^0_{1pt} + M'_{2pt}\left[1 - e^{-\phi(t,\tau)}\right] \qquad (4\text{-}18)$$

| 符号 | 含义 |
|---|---|
| M2pt | 先期结构的预加力（t 时）按后期结构计算的弯矩 |
| M1pt | 先期结构的预加力（t 时）按先期结构计算的弯矩 |
| M⁰1pt = M⁰2pt | 预加力初弯矩，先期、后期结构中相同 |
| M′2pt | 先期结构的预加力按后期结构计算的弹性次弯矩 |
| M′1pt | 先期结构的预加力按先期结构计算的弹性次弯矩，先期结构静定时为零 |
| φ(t, τ) | 简支梁加载龄期 τ（即体系转换龄期）到计算时刻 t 的徐变系数 |

（4）加载龄期 τ0 与转换龄期 τ 相隔较长时，计入先期结构这段时间的龄期影响：

$$M_{gt} = M_{1g} + (M_{2g} - M_{1g})\left(1 - e^{-[\phi(t,\tau_0) - \phi(\tau,\tau_0)]}\right) \qquad (4\text{-}19)$$

$$M_{pt} = M_{1pt} + (M'_{2pt} - M'_{1pt})\left(1 - e^{-[\phi(t,\tau_0) - \phi(\tau,\tau_0)]}\right) \qquad (4\text{-}20)$$

程序：`femotion.codes.jtg.creep`。
- `redistribution_phi(creep, t, tau, tau0=None)`：τ0 不给时为 φ(t, τ)（式 4-12～4-18），给出时为 φ(t, τ0) − φ(τ, τ0)（式 4-19、4-20）；
  t、τ、τ0 都是混凝土龄期（d）；`creep` 为 `concrete_creep(...)`（附录 C，20.4）或任意 φ(t, t0) 函数。
- `creep_redistribution(S1, S2, phi)`：S1 + (S2 − S1)(1 − e^−φ)，即式（4-12）、（4-19），也是式（4-13）。
- `prestress_creep_redistribution(S1, S2_sec, S1_sec, phi)`：S1 + (S′2 − S′1)(1 − e^−φ)，即式（4-17）、（4-20）；S1_sec = 0 为式（4-18）。
- `system_transformation(sv1, sv2, sections, comp, phi, *, w=None, tendons=None)` → `{"dead": Transfer, "prestress": Transfer}`：
  用 `femotion.frame` 分别在先期结构 sv1、后期结构 sv2（同一模型，接缝连上、约束或支座加上）上算同一荷载，按上式合成。自重（或 w）用
  `uniform_load_forces`，钢束用 `femotion.frame.prestress.effects`（总效应、主效应、次效应）。`Transfer.first` = M1g 或 M1pt，
  `second` = M2g 或 M2pt（= M⁰ + M′2，式 4-14），`final` = Mgt 或 Mpt，`creep` = final − first（徐变次效应）。
- 程序约定：
  - 式中的 M 换成任何线性效应都成立（推导只用到叠加和基本结构上的一个多余力）：`comp` 可取 N、Vy、Vz、T、My、Mz（截面 (梁号, "i"|"j")），
    或 "R"（支反力，截面写成 (节点, 自由度 0～5)）。后期结构才有的支座在先期结构上取 0；转换时拆除的临时支座不在适用范围内
    （拆除反力是作用在后期结构上的弹性荷载，可用逐步法）。
  - 式（4-13）～（4-20）按条文说明用 t 时的有效预加力，钢束力按使用者给出的值（一般取全部损失后的 Pe）。
- 适用条件（程序说明，非条文）：推导中后加的多余力增量与原有荷载按同一 dφt 徐变，即徐变速率法（狄辛格法）的"各龄期徐变曲线平行"：
  φ(t, t′) = φ(t, τ) − φ(t′, τ)。在这一徐变律下，逐步法随步长加密以二阶收敛到式（4-12）、（4-17）～（4-20），弯矩、剪力、支反力都一样
  （测试最细步长差 2 × 10⁻⁵）。附录 C 的徐变系数（CEB-FIP 1990）不满足这一条件：后期加载的徐变比平行曲线给的大，多余力增量自身的徐变
  使重分配变小。测试算例（两跨 2 × 20 m 预制梁 28 d 加载并转换，10 年）中支点弯矩：式（4-12）−1013 kN·m，逐步法 −867 kN·m，
  按龄期调整有效模量法（χ = 0.8）−890 kN·m；例子（三跨 3 × 30 m，7 d 加载、67 d 转换）中转换前荷载的徐变次弯矩：式（4-19）+（4-20）
  783 kN·m，逐步法 527 kN·m。条文说明的闭合式偏大，宜用于估算，以逐步法为准。

### 20.5 施工阶段变形和施工阶段分析（6.5.6，p67；条文说明 p204）

6.5.6：预应力混凝土受弯构件要算施工阶段变形时，宜用有限元：按各施工阶段结构中各单元的加载龄期 t0i 和计算龄期 ti，用附录 C 算出各阶段的
收缩、徐变变形增量，逐阶段累加，得到各阶段结构各部位的变形。条文说明（p204）：一般不算施工阶段挠度；大跨径桥施工期长，用悬臂浇筑或
预制拼装时需算悬臂挠度以便控制，这时收缩徐变尚未完成，要按加载龄期和计算龄期算。

程序：`femotion.frame.stages.analyse(m, stages, creep, t_end, *, times=(), first=0.01, per_decade=8, g=9.81)` → `History`。
- `Stage(time, name, beams, age, trusses, links, remove_beams, remove_trusses, remove_links, fix, release, self_weight, w, F, tendons,
  eps0, strain, curvature)`：一个时刻的施工内容。`beams` 本阶段浇筑或架设的梁单元，`age` 它们此刻的混凝土龄期（预制构件为存梁后的龄期）；
  `fix`、`release` 增加、解除的支座；`links` 接缝、支座、铰；`w` 二期恒载等均布荷载；`F` 节点荷载（挂篮、合龙配重，可用负值卸除）；
  `tendons` 本阶段张拉的钢束（`femotion.frame.prestress.Tendon`，力取第一批损失后的值），可带随时间的后期损失函数；`eps0` 拉索张拉；
  `strain`、`curvature` 强加应变和曲率（温度、截面收缩差）。`m.fixed` 为开始就有的支座。
- `creep`：一个 `Creep` 用于全部梁，或 {梁号: Creep}（未列出的梁为钢构件，不徐变），或 None（只算弹性施工阶段）。每个单元用自己的
  龄期（阶段时刻减去激活时的龄期）、理论厚度、湿度和强度等级。
- `History`：每一步（阶段事件和时间步）后的状态。`index(t, before=False)` 取 t 时刻的状态（`before=True` 为该时刻阶段事件之前）；
  `after(阶段)` 阶段刚完成时；`section_forces(k, sections, comp)` 截面内力（符号同 `femotion.frame.post.chain_force`）；
  `reactions(k)` 支反力；`displacements(k, total=False)` 节点位移；`N` 拉索力；`built` 各节点建成时的状态号。
- 位移的两种口径（程序约定）：`displacements(k)` 为自该节点建成以来的位移，预拱度、立模标高用它（目标时刻该值的相反数即需要预留的量）；
  `total=True` 再加上节点建成时继承的位移：经由本阶段新建的梁或连接，取所挂靠的已建部分的刚体位移（平移加转角乘力臂，即沿已变形悬臂端的
  切线接长），只经拉索相连时只继承平移，落在新支座上的部分不继承。
- 后期预应力损失：`jtg.creep.later_losses(Ap, l5, creep, t0, *, Ep, alpha_EP, sigma_pc, rho, rho_ps, fcu_transfer=None)` → 损失函数
  dt ↦ (σl5 × r(dt) + σl6(t0 + dt)) Ap（kN，每单元）。σl5 为 6.2.6 的终极值，r 为表 C.3.1 的比值（`prestress.relaxation_ratio`；
  2 d 以前从张拉时的 0 线性增到 0.50，程序约定）；σl6(t) 按式（6.2.7-1）用该混凝土的 φ(t, t0)、εcs(t, t0)。适用于后张法（表 6.2.8：σlII = σl5 + σl6）。

#### 逐步法（程序实现，非规范条文）

材料律：线性徐变（4.3.9），对每根混凝土梁单元，

$$\varepsilon(t) = \sum_j \frac{\Delta\sigma_j}{E}\left[1 + \phi(t, t_j)\right] + \varepsilon_{cs}(t, t_{act})$$

Δσj 为单元建成后各次应力增量，tj 为其龄期，E 为 Section.E（28 d 弹性模量，不随龄期变化，程序约定），εcs 从单元建成时的龄期 tact 起算。
单元的"应力"取 12 个端力：截面和徐变系数在单元内均匀时，单元的徐变变形与其弹性变形成正比，端力增量 Δpj 的徐变就是约束力 −φΔpj，
轴力、两向弯矩、扭矩、剪力同比例（不计剪切变形）。跨内荷载（自重、w）的固端部分徐变时不引起端部变形，只保留端力部分进入历史。

积分（Bažant 1972 的逐步法；参考 Bažant, *Mathematical Modeling of Creep and Shrinkage of Concrete*, 1988, 第 2 章）：每个阶段是一个长度为零的
弹性步；阶段之间的时间步从阶段后 `first` 天起按每十倍时间 `per_decade` 步几何增长，再插入 `times` 和下一阶段时刻。时间步 k（tk−1 → tk）内
发生的应力增量取在步内对数时间的中点 tk−½（第一个步取算术中点），于是每根混凝土梁的有效模量和约束力为

$$E'' = \frac{E}{1 + \phi(t_k, t_{k-1/2})}$$

$$\Delta r_k = -\frac{1}{1 + \phi(t_k, t_{k-1/2})}\left[\sum_{j<k}\left(\phi(t_k, t_{j-1/2}) - \phi(t_{k-1}, t_{j-1/2})\right)\Delta p_j + EA\,\Delta\varepsilon_{cs,k}\,(\text{轴向})\right]$$

然后在当前结构（已建构件、当前支座；钢构件、拉索、连接用弹性刚度）上解 K″Δu = 残余力，得端力增量 Δpk = (E″/E)·k·T·Δue + Δrk
（k 为单元刚度，T 为坐标变换，Δue 为单元节点位移增量），存入历史。残余力 = 外荷载累计 − 各构件内力的节点合力，因此新加支座在当前位置固定，解除的支座把反力还给结构，拆除的构件把端力
还给结构、其跨内荷载一并消失，都不需单独处理。钢束张拉、后期损失都以等效荷载（`femotion.frame.prestress.equivalent_loads`）加上；
强加应变、收缩用 `femotion.frame.thermal.restrained_end_forces` 的约束力做法。

假定和限制（程序约定）：
- 钢束不进入刚度（净截面），也不由逐步法求钢束与混凝土的变形协调；钢束力随时间的变化由损失函数给出（一般为 6.2.6、6.2.7）。
- 混凝土截面不计普通钢筋和预应力钢筋对徐变、收缩的约束（截面性质取 Section 的 A、I，可用换算截面）；收缩只计截面均匀收缩，
  截面内的收缩差（如组合梁）用 `strain`、`curvature` 加入。
- 小变形线性；新建节点在建成前不动；同一梁不能拆除后再建。
- 精度：二阶收敛。徐变在加载后极短时间内增长最快，第一个时间步的误差随 `first` 减小。默认值（0.01 d、每十倍 8 步）：徐变速率法算例与
  闭合解差 3.5 × 10⁻⁴；附录 C 徐变的同一算例与极细步长（10⁻⁶ d、每十倍 64 步）的结果差 4 × 10⁻⁵；固结杆收缩约束力差 0.2%。
- 结构成为机构（LU 主元比小于 10⁻¹³）时报错并给出时刻和阶段名。
- 计算量：步数 n 时徐变历史为 O(n²)；40 个悬臂节段（各自龄期）、1000 多个时间步约 3 s。
