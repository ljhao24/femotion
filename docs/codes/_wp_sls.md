## 1 先张法构件传递长度内的抗裂验算（6.1.8，p55；条文说明 p194–195，图 5-1 见 p173）

**条文要点**（6.1.8）：先张法构件端部区段做正截面、斜截面抗裂验算时，传递长度 ltr 范围内预应力钢筋的实际应力在构件端部取 0，
在传递长度末端取有效预应力 σpe，两点之间按直线变化（图 6.1.8）；ltr 按表 6.1.8（主文档 6.10 节）。表 6.1.8 注 3：骤然放松时
ltr 从离构件末端 0.25 ltr 处起算。

**条文说明**（p194–195）：
- 在端部锚固区段内（**不计图 5-1 中端部失效的部分**），受锚固传递应力的影响，钢筋实际应力按曲线变化，可近似按直线变化。
- 表 6.1.8 的 ltr 由下式算得：

$$l_{tr} = \beta\,\frac{\sigma_{pe}}{f_{tk}}\,d \qquad (6\text{-}1)$$

  σpe：放张时预应力钢筋的有效预应力；β：外形系数，七股钢绞线 0.16，螺旋肋钢丝 0.14；ftk：混凝土轴心抗拉强度标准值；
  d：公称直径（mm），束筋取等效直径 √n·d（n 为单筋根数）。
- 表值按表列强度等级和 σpe 求得；放张时的强度等级不在表列值时在相邻两级之间直线内插，σpe 不是表列值时再按实际值与表列值之比增减。

**条文说明 5.1.6 与图 5-1**（p173）：先张法构件常在预应力钢筋端部套硬塑料套管或包硬塑料（使该段钢筋与混凝土不黏结，即"失效段"）；
失效长度不宜过长，从抗弯或抗剪承载力控制截面起算的锚固长度应满足表 5.1.6。

**程序**：`jtg.Transfer(x, ltr, abrupt=False, debond=0.0)`，传给 `jtg.crack_resistance(…, transfer=)`（6.3.1 第 1 款）、
`jtg.principal_stresses(…, transfer=)` 和 `jtg.inclined_crack_resistance(…, transfer=)`（6.3.1 第 2 款、6.3.3）。

- x：计算截面到**构件端面**的距离（mm；图 6.1.8 以构件端部为零点，不是支座中心线）；ltr：传递长度（mm，`prestress.transfer_length`），
  一个值或每束一个值（各束直径、σpe 不同时 ltr 不同）。
- 每束的系数 k = (x − s)/ltr，限制在 0～1；起点 s = debond，骤然放松时 s = debond + 0.25 ltr。截面上该束的 σp0 和 σpe 都乘 k
  （`Transfer.apply`），其余照常：σpc 按式（6.1.6-1）由 Np0 作用于换算截面算得，弯起钢筋项的默认 σ″pe 也随之折减。
- 结果 `details["transfer_factor"]` 给出各束的 k，条文号加注 6.1.8。

程序约定及理由：
1. **σp0 与 σpe 乘同一个 k**：条文给的是钢筋实际应力（σpe）的直线变化；先张法的 σp0 = σcon − σl + σl4（式 6.1.6-2），比 σpe 多出的
   σl4 = αEP σpc（式 6.2.5-2）与该处已传递的预压力成正比，所以 σp0 也按 k 变化，Np0 与已传递的力成正比。
2. **普通钢筋的 σl6 不折减**：6.1.8 只说预应力钢筋的应力；式（6.1.7-1）中 σl6·As 按截面给定的值计入（端部徐变小、σl6 偏小时，
   使用者可对端部截面传较小的 `sigma_l6`）。
3. **失效段**（`debond`）：条文说明 6.1.8 把图 5-1 的失效部分排除在端部锚固区段之外，程序把传递长度的起点后移一个失效长度；骤然放松时
   再加 0.25 ltr（程序约定：表 6.1.8 注 3 从构件末端算起，失效钢筋的黏结从套管末端开始）。
4. **适用范围**：6.1.8 只针对抗裂验算，所以只在上面三个函数里接参数；`Transfer.apply(sec)` 是公开的，使用者需要时可以把折减后的截面
   用于其他验算（如使用阶段应力），规范对此没有规定。后张法构件报错（6.1.8 是靠黏结传递的先张法）。
5. **x 超过传递长度**（k 全为 1）时结果与不传 `transfer` 逐位相同。

校核（`tests/test_sls_extra.py`）：表 6.1.8 与条文说明式（6-1）逐格吻合（表值取整到 1d 以内）；无普通钢筋时 σpc 与 k 成正比、端面为 0；
传递长度以外逐位等于原验算；越近端部主拉应力越大、端面 σtp = τ。

## 2 短暂状况（7.2.1～7.2.3、7.2.6、7.2.8，p71–73；条文说明 p206–207）

### 2.1 施工荷载与吊机（7.2.1）、动力系数（7.2.2）

**条文要点**：
- 7.2.1：短暂状况设计计算制作、运输、安装等施工阶段由自重、施工荷载等引起的正截面和斜截面应力，不得超过本节限值。施工荷载除另有规定外
  用标准值；有组合时不计组合系数。吊机（车）行驶在桥上进行安装时，要验算已安装就位的构件，吊机（车）荷载乘分项系数 **1.15**；吊机（车）
  产生的效应设计值小于持久状况承载能力极限状态的作用效应设计值时，可以不验算。
- 7.2.2：运输、安装计算时构件自重乘动力系数，按 JTG D60—2015（4.1.10：不利时 1.2，有利时 0.85，可按实际情况增减，
  `jtg.DYNAMIC_FACTOR`）。
- 条文说明 7.2.1（p206）：短暂状况的应力计算实为弹性阶段的强度计算，施工荷载用标准组合（另有规定者除外）；短暂状况一般不做正常使用
  极限状态计算，可用施工措施或构造弥补，防止过大变形和不必要的裂缝。

**程序**：`jtg.transient_rc(sec, Mk=0, Vk=None, *, fcu, M_G=0, V_G=None, M_crane=0, V_crane=None, lifting=False, dynamic=None,
crane_factor=1.15, Ec=None, stirrups=None, stirrup_steel=None)`、`jtg.transient_pc(sec, M=0, *, fcu, M_G=0, M_crane=0, lifting=False,
dynamic=None, crane_factor=1.15, grouted=False, M_p2=0, Ec=None)`；`jtg.CRANE_FACTOR = 1.15`。

- 荷载分三份传入（kN·m、kN，弯矩正弯矩为正）：`Mk`/`M`、`Vk` 为其他施工荷载；`M_G`、`V_G` 为构件自重；`M_crane`、`V_crane` 为行驶在
  已安装构件上的吊机（车）。合计 = 其他 + k·自重 + 1.15·吊机；除动力系数 k 和吊机的 1.15 外，各项系数都是 1.0（7.2.1 不计组合系数）。
- `lifting=True`（运输、吊装）时自重乘动力系数：1.2 和 0.85 **两个都算**，每项限值各取不利的一个（`transient_pc` 的压应力和拉应力分别取；
  `transient_rc` 的 σtcc、σtsi、σttp 分别取）。`details` 中 `dynamic_factor` 是压应力控制的系数，`dynamic_factor_tension` 是拉应力控制的
  系数，`cases` 列出各组。`dynamic=` 可覆盖：一个数或几个数（D60 允许按实际情况增减），`True` 用 D60 的两个，`False` 或 1.0 关闭。
- 条文号：用了吊机加注 7.2.1，用了动力系数加注 7.2.2。

程序约定及理由：
1. **"不利""有利"不预先判断**：同一个自重对不同边缘、不同限值作用相反（预应力构件的自重常使预拉区边缘的拉应力减小），所以两个系数都算，
   各项限值取较不利的结果。
2. **动力系数只乘被吊运构件的自重**：吊机行驶在已就位构件上时，被验算构件的自重是静载，不乘动力系数（`lifting=False`，只传 `M_crane`）。
3. **7.2.1 的"可不验算"不判断**：条文没有说清"吊机产生的效应设计值"是吊机单独的效应还是含自重的组合；程序照算，算了不会错，
   要不要省略由使用者判断。

### 2.2 施加预应力时的强度和弹性模量（7.2.3）

**条文要点**（7.2.3）：施加预应力时，混凝土的立方体强度不低于设计强度等级的 **80%**，弹性模量不低于混凝土 28 d 弹性模量的 **80%**。
条文说明（p206–207）：过早施加预应力，收缩徐变尚在初期，损失大、可能引起微裂；掺早强剂的混凝土强度上得快而弹性模量跟不上，施加预应力后
变形很大；本条参照 JTG/T F50—2011 第 7.7.4、7.8.5 条把强度要求调为 80%，并补充了弹性模量要求。

**程序**：`transient_pc` 的 `fcu` 低于 0.8 × 设计等级（fcu,k）、或给了 `Ec` 且低于 0.8 × 28 d 的 Ec 时，写进 `warnings`。
`Ec=`（两个短暂状况函数都有）是该阶段的弹性模量，用于 αES、αEP（换算截面、净截面、开裂截面），不给时取 28 d 值（主文档 8.3 节原约定）。

程序约定及理由：
1. **进 warnings 不进 failed**：7.2.3 是对施工时材料状态的要求（施加预应力的时机），不是对截面应力的计算，按"构造只警告"的规则
   与 3.1.2 的强度等级下限同样处理。
2. **每个阶段都查**：施加预应力以后混凝土强度只增不减，后续阶段的 f′cu 不低于张拉时的值，所以对任何阶段查都不会误报；
   `transient_rc` 不查（钢筋混凝土构件不施加预应力）。

### 2.3 按剪应力图配置箍筋和弯起钢筋（7.2.5、7.2.6，图 7.2.6）

式（7.2.5）、（7.2.6-1）～（7.2.6-3）见主文档 8.3 节。图 7.2.6 的意思（转述）：沿梁长画中性轴处的剪应力图，自支点的 τmax 向剪力零点减小；
τ ≤ 0.25 f′tk 的区段 b 由混凝土承担；τ > 0.25 f′tk 的区段 a 由箍筋和弯起钢筋承担：箍筋承担高度为 τv 的矩形部分（式 7.2.6-2），
弯起钢筋承担 a 区段内 τv 以上的部分，面积为 Ω（式 7.2.6-3）。

**程序**：`jtg.transient_shear(x, tau, *, fcu, b, stirrups=None, steel="HRB400", stirrup_steel=None, Asb=None)` → `Check`。
- x（mm，递增）、tau（MPa）为沿梁的站点和剪应力，可取各站点 `transient_rc(…).details["sigma_tp"]`；站点之间按直线。
- `demand` = τmax，限值 f′tk（式 7.2.5，超过为不满足）。
- a = {τ > 0.25 f′tk} 的总长；τv = n Asv1 [σts]/(b sv)（不给箍筋时 τv = 0）；Ω = ∫a max(τ − τv, 0) dx（分段线性，先在 τ 与 0.25 f′tk、
  τv 的交点处细分，再逐段精确积分）；所需 Asb = bΩ/(√2 [σts])。给了 `Asb`（区段 a 内弯起钢筋总面积）则检查，不足列入 `failed`。
- `details`：a、区段 a 的起止（`x_a`）、τv、Ω、`Asb_needed`。

程序约定及理由：
1. τ 取绝对值；区段 a 可以不连续（取所有 τ > 0.25 f′tk 的部分），Ω 只在区段 a 内积分（图 7.2.6 中 Ω 在区段 a 之内）。
2. [σts] = 0.75 fsk（7.2.4）：箍筋用箍筋钢种的 fsk，弯起钢筋用弯起钢筋钢种的 fsk（3.2.3 表注 2：同一构件中不同钢筋各用各的强度）。
3. 式（7.2.6-3）的 √2 对应 45° 弯起；其他角度规范没有给，程序不做。弯起钢筋沿梁长的具体布置（各排弯起点与 Ω 的分配）由使用者按图做。

校核：三角形剪应力图的闭合解（τv ≥ 0.25 f′tk 时 Ω = (τmax − τv)² L/(2τmax)，否则为梯形 a[(τmax + 0.25f′tk)/2 − τv]）；不规则剪应力图对照
10⁶ 点中点积分；加密站点结果不变；`transient_rc` 的开裂截面应力满足 C = T、T·z0 = M。

### 2.4 预拉区纵向钢筋（7.2.8）

7.2.8 末段（转述）：预拉区纵向钢筋宜用带肋钢筋，直径不宜大于 14 mm，沿预拉区外边缘均匀布置。条文说明（p207）：σtct ≤ 0.70 f′tk 时一般不会
开裂，但混凝土抗拉强度离散大，仍要配一定数量的纵筋以分布可能的裂缝；σtct = 1.15 f′tk 时开裂可能性大，配筋更多；预拉区纵筋直径尽量小，
有利于裂缝分布均匀。

**程序**（`transient_pc`）：
- 配筋率（0.2%～0.4%）不足、预拉区内有 HPB300（光圆）钢筋、预拉区内钢筋直径大于 14 mm：写进 `warnings`；预拉区内有直径未知的钢筋
  （`bar_d` 为 NaN）：写进 `notes`，不查直径。
- σtct > 1.15 f′tk 仍列入 `failed`。
- 整个截面都受拉（没有受压边缘）时，预拉区取全截面。

程序约定及理由：**7.2.8 的配筋率放 warnings**。它是随 σtct 变化的最小配筋率，作用是分布可能出现的裂缝（条文说明），不改变截面应力，
与 9.1.12、9.1.13 的最小配筋率同属"构造只警告"；拉应力上限 1.15 f′tk 是应力计算，仍判不满足。原来的程序把配筋率不足列入 `failed`，已改。

## 3 两端张拉的锚具变形损失（附录 G.0.3，p137–138；条文说明 p260）

**条文要点**（G.0.3）：同一根钢筋两端张拉（分别张拉或同时张拉），两端的反向摩擦影响长度有重叠时，重叠范围内某截面扣除正摩擦和回缩
反向摩擦损失后的钢筋应力，可以这样取：假定两端分别张拉、锚固，分别算正摩擦和回缩反向摩擦损失，各以张拉端锚下控制应力减去算得的损失，
取两者中的较大值。

**条文说明**（p260，转述）：锚固前扣除正摩擦后的应力分布假定为直线 caa′（图 G-1）；锚固时回缩 ΣΔl，反向摩擦损失在张拉端最大、到 lf 处为零；
正、反向摩擦系数相同，两条直线斜率相同、方向相反，所以张拉端损失 Δσ = 2Δσd lf（G-1），Δσd = (σ0 − σl)/l；由 ΣΔl = ∫Δσx/Ep dx =
Δσd lf²/Ep 得 lf = √(ΣΔl·Ep/Δσd)（G-2）。**式（G-2）只适用于一端张拉且 lf 不超过构件全长**；lf 超过全长时只能按 l 范围内钢筋变形与
回缩协调试算。

**程序**：`prestress.anchorage_loss_two_ends(sigma_con, sigma_end, l, dl, Ep, x, *, dl_b=None, friction=None)` →
(σl1 + σl2 在 x 处, (lf,A, lf,B))。
- 两端 A（x = 0）、B（x = l）轮流作张拉端，另一端作锚固端，按全长 l 用 G.0.2（`anchorage_loss_reverse`，lf > l 时用式 G.0.2-5）：
  σl,A = σl1,A + σl2,A，σl,B 同理（x 量自 A 端，B 端的距离为 l − x）。
- 区段划分：A 的反向摩擦影响范围 x < lf,A，B 的 l − x < lf,B。只在一端范围内：取该端的损失；两端范围重叠处：取两者中较小的损失（即较大的
  钢筋应力，G.0.3）；两端范围之外：取较小的损失（即从损失较小的一端算摩擦）。
- `sigma_end`：从一端张拉、扣除全长摩擦后另一端的应力（σl，式 G.0.2-2）；两端相同，因为全长的转角之和与管道长度与方向无关
  （式 6.2.2 的指数相同）。`dl`、`dl_b`：A、B 两端的 ΣΔl（不给 `dl_b` 时取 `dl`）。`friction=(σl1,A, σl1,B)`：各站点从两端算的摩擦
  损失（`friction_loss`，按式 6.2.2 精确算）；不给时取图 G.0.2 的直线 Δσd·x、Δσd·(l − x)，Δσd = (σcon − σend)/l。
- 两端张拉控制应力相同（条文"张拉端锚下控制应力"指同一个 σcon）。

程序约定及理由：
1. **两端范围之外取较小损失**：条文只规定重叠范围；两端都不受回缩影响的区段，两端张拉后的应力取决于摩擦较小的一端，这是两端张拉的通常
   算法（主文档例子 `jtg_pc_girder.py` 的摩擦也是从较近的一端算）。
2. **重叠范围边缘的跳变**：按条文，重叠范围内取较大应力、范围外取本端结果，两者在重叠范围的边缘不连续；对直线摩擦，A 端一侧的跳变为
   Δσd(2lf,A − l)（lf,A > l/2 时），B 端同理。程序照条文，不做光滑处理（例子 `jtg_pc_girder.py` 的 30 m 直线束打印了这一分布）。
3. （程序说明，非条文）两端**同时**张拉、两端 ΣΔl 相同时，按图 G.0.2 的直线假定，跨中截面不动，每半根钢筋等同于一端张拉、锚固端在跨中、
   长度 l/2 的钢筋，用 G.0.2（lf > l/2 时用 G.0.2-5）可以精确求解；两端范围不重叠时这与 G.0.3 的结果完全相同（测试核对），重叠时两者不同，
   以规范的 G.0.3 为准。

校核：两端相同时损失左右对称；不重叠时等于"半根钢筋一端张拉"的另一种算法；重叠时与数值解（单端的回缩协调用求根 + 数值积分求解，
不用闭合式）逐点吻合；两端 lf 都超过全长、两端 ΣΔl 不同（一端为 0）的极限情况；传入精确摩擦时的对称性。

## 4 组合式受弯构件的负弯矩区和 B 类构件（8.1.8、8.1.9，p76–77；条文说明 p208–209）

**规范写到的范围**：8.1.8 针对**使用阶段要求不出现裂缝**的预应力混凝土组合式受弯构件（全预应力、A 类），抗裂验算边缘在预制构件上
（σpc 取预制构件抗裂边缘的预压应力，ftk 取预制构件混凝土的），式（8.1.8-1）～（8.1.8-3）按简支组合梁的正弯矩写出（主文档第 16 节）。
8.1.9 的斜截面抗裂按全预应力、A 类的要求。

**规范没有写到的**：
1. 抗裂验算边缘在现浇层上（先简支后连续等的**负弯矩区**，第二阶段负弯矩使现浇层受拉）；
2. 现浇层与预制构件结合后才张拉的预应力（负弯矩钢束）；
3. B 类组合构件：8.1.8 不适用（允许开裂），8.1.10～8.1.11 的裂缝宽度只写了钢筋混凝土组合构件，8.1.13 的刚度只写了钢筋混凝土和全预应力、
   A 类，8.1.17 只说按 7.1 节考虑组合结构的受力特点。

**程序**（`jtg.composite_crack_resistance(comp, *, M1k, M1Gk, M2s, M2l, pc_class, segmental=False, sigma_extra=0, sigma_pc2=0, M2Gk=None)`）：
- 弯矩带符号（正弯矩为正）。预制构件（第一阶段）验上、下两个边缘：σst = M1k/W01（式 8.1.8-1）；组合构件验预制构件上、下边缘和现浇层顶面：
  预制构件边缘 σst = M1Gk/W01 + M2s/W0、σlt = M1Gk/W01 + M2l/W0（式 8.1.8-2、-3，W01、W0 取该边缘的值），现浇层顶面
  σst = n M2s/W0、σlt = n M2l/W0（n = Ec,现浇/Ec1，W0 为换算成预制构件混凝土的组合截面在该边缘的抵抗矩）。各边缘按 6.3.1 的限值判断，
  报告余量最小的边缘，`details["edges"]` 列出全部（与 `jtg.crack_resistance` 相同）。
- σpc：预制构件边缘取预制构件预加力在该处的应力（8.1.8）；现浇层边缘取 0；再加 `sigma_pc2`（组合后施加的预应力在各边缘的实际应力）。
  ftk：预制构件边缘取预制构件的，现浇层边缘取现浇层的。
- `jtg.composite_prestress_stress(comp, tendons, *, M_p2=0)` → σ(z)：组合后张拉的钢束（行：Ap、距组合截面顶面的深度、σpe、管道直径，
  同 `jtg.rect` 的钢束行）在组合截面上产生的混凝土应力（压为正，实际应力）：力 Σσpe Ap 作用在换算成预制构件混凝土的组合截面上
  （预制构件的管道已压浆，按换算截面），扣除这些钢束自己的管道（在现浇层内的乘 n），即后张法的净截面（6.1.5 第 2 款、式 6.1.6-4）；
  次弯矩 `M_p2` 作用在同一截面上；现浇层内的应力乘 n。结果用于 `sigma_pc2`，也可传给 `composite_principal_stresses` 的 `sigma_cx`
  和 `composite_service_stresses` 的 `sigma_pc2`。
- B 类（`pc_class="B"`，需 `M2Gk`，第二阶段的结构自重即桥面系）：按 6.3.1 第 1 款第 3 项，只有结构自重作用时，频遇组合下受拉的边缘（都不受拉时
  取最接近消压的边缘）仍须受压：预制构件 M1Gk/W01 ≤ σpc，组合构件 M1Gk/W01 + M2Gk/W0 ≤ σpc（现浇层顶面 n M2Gk/W0）。
- `jtg.composite_inclined_crack_resistance(…, pc_class="B")`：取 A 类的限值 0.7 ftk（预制）、0.5 ftk（现浇）。
- `jtg.composite_service_stresses(…, sigma_pc2=)`：组合后施加的预应力加到三个边缘的法向应力上（它对预制构件钢束 σpe 的影响，即附加的
  弹性压缩损失，由使用者计入）。

程序约定及理由：
1. **三个边缘都验算**：正弯矩区预制构件下缘控制；负弯矩区现浇层顶面和预制构件上缘受拉，要验算的边缘就在这里。式（8.1.8-2）、（8.1.8-3）
   的写法（第一阶段在预制截面上、第二阶段在组合截面上叠加）对预制构件上缘同样成立。
2. **现浇层边缘不计第一阶段、不计预制构件的预加力**：第一阶段荷载由预制构件单独承担，现浇层不受力；预制构件的预应力在浇筑现浇层之前
   已经施加。徐变使预制构件的预压力向现浇层重分布，规范对预制构件边缘也没有计入，程序同样不计。
3. **现浇层边缘用现浇层的 ftk**：8.1.8 指定预制构件的 ftk，是因为它的抗裂验算边缘在预制构件上；边缘在现浇层时开裂由现浇层混凝土决定。
4. **B 类的自重验算**是 6.3.1 第 1 款第 3 项套用 8.1.8 的两阶段写法（8.1.8 本身只针对不允许开裂的构件）；8.1.9 对 B 类取 A 类限值，
   因为式（6.3.1-7）、（6.3.1-8）对 A 类和 B 类是同一个限值。
5. 组合后张拉钢束的次弯矩（连续梁）、体系转换后的徐变次效应由使用者另算（`femotion.frame.prestress`、`femotion.frame.stages`），
   传 `M_p2` 或并入第二阶段弯矩。

校核：现浇层与预制构件同一强度等级、第一阶段弯矩为零时，第二阶段应力等于直接用 `jtg.tee` 建的整体 T 形截面的应力（另一种建模途径）；
现浇层强度不同时现浇层应力为 n 倍；`composite_prestress_stress` 的应力场按实际截面（现浇层实际宽度和实际应力、扣管道、钢筋按 αE）
数值积分，合力等于钢束力、对钢束的合力矩为零，次弯矩部分合力为零、合力矩等于 Mp2；负弯矩区加组合后的钢束后，各边缘的 σpc 恰好增加
σ(z)；B 类两阶段自重应力手算。
