## 4.6 圆形截面抗剪（3362 未规定；借用 GB 50010—2010 第 6.3.15 条，程序约定）

**3362 有没有规定**：没有。5.2.9（p28）写明适用于矩形、T 形和 I 形截面的受弯构件；5.3、5.4（p33–42）、9.6（p116–117，只有柱的箍筋构造）
和第 5 章条文说明（p179–184）都没有圆形截面的斜截面抗剪条文，官方英文版全文检索也没有。圆形截面只在 8.4、8.5 里为确定盖梁、承台的
计算截面位置换算成边长 0.8 倍直径的方柱（几何换算，不是抗力规定）。JTG 3363—2019（地基与基础）也没有桩身抗剪公式；
JTG/T 2231-01—2020 第 7.3.5 条只要求按 JTG D62（现 3362）验算单桩截面强度。

**借用的条文**：GB 50010—2010（2024 年版）第 6.3.15 条：圆形截面的受弯构件和偏心受压、受拉构件，截面限制条件和斜截面受剪承载力
按该规范矩形截面的条文计算，但公式中的 b、h0 分别换成 1.76r、1.6r（r 为圆截面半径）；算出的箍筋截面面积作为圆形箍筋的截面面积。
条文说明：依据国内外圆形截面受弯、偏压构件的试验数据，参考国外规范，按等效惯性矩原则定出等效宽度和等效高度。

**程序**：`jtg.shear_circle(section, Vd, stirrups=(肢数, 直径, 间距), *, gamma0=1.0, alpha1=1.0, stirrup_steel=None, bent=(), pile=False)`；
`jtg.shear` 遇到圆形截面自动转到这里（`pile` 取默认 False）。

- 把 b = 1.76r、h0 = 1.6r 代入 3362 的式（5.2.9）（α2 = 1、α3 = 1）、5.2.11 的截面上限和 5.2.12 的构造配箍门槛。
- 式（5.2.9）里的 P = 100ρ：ρ = As /(b h0)，As 取圆心以外（受拉一侧）半圆内的纵筋（程序约定；与 AASHTO LRFD 把圆截面有效高度取到半圆
  钢筋合力点 de = r + 2rs/π 的做法一致）。
- 箍筋：一道圆形箍筋或螺旋筋按 2 肢计（`stirrups=(2, d, s)`），拉筋另加肢数。这是对"计算所得的箍筋截面面积应作为圆形箍筋的截面面积"
  的读法：与矩形封闭箍筋一样，一道圆箍在截面上算两肢（《混凝土结构设计计算算例》第 8.3 节的算例即按此配：圆箍算 2 肢，
  圆箍加一道拉筋算 3 肢）。
- 构造：箍筋直径不小于 8 mm（9.6.1 第 3 款）；柱（`pile=False`）箍筋间距不大于 15 倍纵筋直径、0.8 倍直径和 400 mm（9.6.1 第 4 款）；
  9.6.1 不适用于沉桩和钻（挖）孔桩，`pile=True` 时不查间距。梁的 9.3.12 不适用于墩柱、桩，不查。
- 轴力不计（与 5.2.9 一致）。受拉的桩（如抗拔桩）偏于不安全：GB 50010 第 6.3.14 条对偏心受拉构件扣减 0.2N，程序未采用，由使用者另行考虑。
- 空心圆截面：GB 50010 第 6.3.15 条只说圆形截面，没有站得住的依据，仍报 `NotImplementedError`（上述算例书把环形截面折算成方箱形，
  b = 1.76(r2 − r1)、h0 = 1.6 r2，属作者推广，未采用）。

**为什么选它、其他做法差多少**（φ1.5 m、C35、28Φ28、rs = 0.9r、Φ12 圆箍 @100，同一个式 5.2.9）：

| 做法 | b | h0 | Vcs 相对本做法 |
|---|---|---|---|
| GB 50010 第 6.3.15 条（采用） | 1.76r | 1.6r | 0 |
| AASHTO LRFD 圆形截面的 bv = D、h0 取 de = r + 2rs/π | 2r | 1.573r | +4.0% |
| 同上、h0 取 dv = 0.9de | 2r | 1.416r | −5.7% |
| 3362 8.4、8.5 的 0.8D 方柱（几何换算借来作抗剪截面） | 1.6r | 1.6r − (r − rs) | −9.5% |
| 圆箍只算 1 肢（"箍筋面积"的另一种读法） | 1.76r | 1.6r | −29%（√0.5） |

选 GB 50010 第 6.3.15 条：它是国内现行规范里唯一直接规定圆形截面受剪的条文，覆盖受弯、偏压、偏拉构件，换算只改 b、h0，可以原样套进
3362 的公式。JTG/T 2231-01—2020 第 7.3.4 条（墩柱塑性铰区抗剪，Vs = 0.1·(π/2)·Asp fyh D′/s）是 E2 地震下按能力保护、随位移延性
折减混凝土项的专用公式，不是持久状况的承载力验算，未采用；按它的桁架项，一道圆箍提供的抗剪约为 GB 两肢读法的 0.9 倍
（π/2·D′ 与 2×1.6r 之比，D′ ≈ 1.8r），两肢读法在 3362 公式中只进根号，影响约 5%。

**校核**：`tests/test_members.py`：与按 b = 1.76r、h0 = 1.6r 建的矩形截面调用 `jtg.shear` 的结果逐位一致；算例书中 r = 225 mm 换算得
b = 396 mm、h0 = 360 mm。

## 5.10 螺旋箍筋或焊接环式间接钢筋的轴心受压构件（5.3.2，p33–34；9.6.2，p117；条文说明 p179）

长细比 l0/i ≤ 48、间接钢筋换算面积 Aso 不小于全部纵筋面积的 25%、间接钢筋间距不大于 80 mm 且不大于 dcor/5 时：

$$\gamma_0 N_d \le 0.9\,(f_{cd} A_{cor} + f'_{sd} A'_s + k f_{sd} A_{so}) \qquad (5.3.2\text{-}1)$$

$$A_{so} = \frac{\pi d_{cor} A_{so1}}{s} \qquad (5.3.2\text{-}2)$$

| 符号 | 含义 |
|---|---|
| Acor、dcor | 构件核心截面的面积、直径 |
| Aso | 间接钢筋的换算截面面积 |
| k | 间接钢筋影响系数：C50 及以下 2.0；C50～C80 取 2.0～1.7，中间直线内插（与 5.7.2 相同） |
| Aso1 | 单根间接钢筋的截面面积 |
| s | 沿构件轴线方向间接钢筋的螺距或间距 |

- 上述条件不满足，或式（5.3.2-1）算得的值小于式（5.3.1）时，不计间接钢筋的套箍作用，按 5.3.1 计算。
- 式（5.3.2-1）的抗压承载力不大于式（5.3.1）的 1.5 倍。
- 9.6.2（构造）：纵筋面积不小于核心面积的 0.5%；核心面积不小于整个截面面积的 2/3；间接钢筋螺距（间距）不大于核心直径的 1/5、
  不大于 80 mm，也不小于 40 mm；间接钢筋直径不小于纵筋直径的 1/4，且不小于 8 mm。
- 条文说明（p179）：沿用原规范；高强混凝土的套箍系数降低（80 MPa 混凝土约 1.8，普通强度 2.0～2.1），所以 C50 以上 k 由 2.0 降到 1.7。

**程序**：`jtg.axial_spiral(section, Nd, l0=None, *, spiral=(直径, 螺距), dcor=None, gamma0=1.0, spiral_steel=None, b_min=None, i_min=None)`。

- `dcor` 默认（`jtg.circle` 截面）：纵筋所在圆的直径加一根纵筋直径，即螺旋筋紧贴纵筋外侧的内径（程序约定）；其他截面须给出。
- 适用条件（l0/i ≤ 48、Aso ≥ 0.25A′s、s ≤ min(80, dcor/5)）不满足，或 5.3.2-1 小于 5.3.1 时，抗力取 `jtg.axial`（5.3.1）的结果并给出说明；
  否则取 min(5.3.2-1, 1.5 × 5.3.1)。i 的取法同 `jtg.axial`（圆、空心圆、矩形自动，其他截面给 `i_min` 或 `b_min`）。
- 计入螺旋筋时另查 9.6.2 的纵筋不少于 0.5% Acor、Acor ≥ 2A/3、s ≥ 40 mm、螺旋筋直径不小于 max(8 mm, d/4)；9.1.12 照常由 5.3.1 查。
- 原文 5.3.2 写"间距不大于 80 mm 或 dcor/5"，9.6.2 第 2 款写明两者都要满足，程序取两者的较小值。
- 预应力截面报错（5.3.2 是钢筋混凝土条文）。
- 校核：式（5.3.2-1）手算；间接钢筋项与 Richart 等（1928）的约束混凝土强度 f′cc = f′c + 4.1 fl（fl = 2 fsd Aso1 /(dcor s)）比较：
  4.1 fl Acor = 2.05 fsd Aso，即 k ≈ 2 的来源；各适用条件和 1.5 倍上限逐项验证。

## 5.11 沿截面腹部均匀配置纵向钢筋的偏心受压构件（5.3.7，p37–38；条文说明 p180–181）

腹部均匀配置纵向普通钢筋（每排不少于 4 根）的矩形、T 形和 I 形截面钢筋混凝土偏心受压构件：

$$\gamma_0 N_d \le f_{cd}\left[\xi b h_0 + (b'_f - b) h'_f\right] + f'_{sd} A'_s - \sigma_s A_s + N_{sw} \qquad (5.3.7\text{-}1)$$

$$\gamma_0 N_d e \le f_{cd}\left[\xi (1 - 0.5\xi) b h_0^2 + (b'_f - b) h'_f \left(h_0 - \frac{h'_f}{2}\right)\right] + f'_{sd} A'_s (h_0 - a'_s) + M_{sw} \qquad (5.3.7\text{-}2)$$

$$N_{sw} = \left(1 + \frac{\xi - \beta}{0.5\beta\omega}\right) f_{sw} A_{sw} \qquad (5.3.7\text{-}3)$$

$$M_{sw} = \left[0.5 - \left(\frac{\xi - \beta}{\beta\omega}\right)^2\right] f_{sw} A_{sw} h_{sw} \qquad (5.3.7\text{-}4)$$

| 符号 | 含义 |
|---|---|
| Asw、fsw | 腹部均匀配置的全部纵筋面积、其强度设计值 |
| Nsw | 腹部纵筋承担的轴力；ξ = x/h0 > β 时取 fsw Asw |
| Msw | 腹部纵筋的内力对受拉边（或受压较小边）钢筋 As 重心的力矩；ξ > β 时取 0.5 fsw Asw hsw |
| hsw | 腹部均匀配筋区段的高度，取 h0 − a′s |
| ω | hsw / h0 |

- σs：ξ ≤ ξb 时取 fsd；ξ > ξb 时按原文"式（5.2.5-1）"计算——应为式（5.1.5-1），见文末"原文问题"。
- 计入受压较大边的 A′s 时要求 x ≥ 2a′s；不满足时：

$$\gamma_0 N_d e' \le f_{sd} A_s (h_0 - a'_s) + M'_{sw} \qquad (5.3.7\text{-}5)$$

$$M'_{sw} = 0.5 f_{sw} A_{sw} h_{sw} \qquad (5.3.7\text{-}6)$$

- T 形、I 形截面 x ≤ h′f 时按宽 b′f 的矩形计算；I 形截面 x > h − hf 时计入受压较小边翼缘受压的部分。
- 注（p38）：算出的 ξ > h/h0 时，各式中的 ξ 取 h/h0，但 As 的应力仍按算出的 ξ。
- 条文说明（p180–181）：参照 GBJ 10—89；承载力分为混凝土与 A′s、As 的部分和腹部钢筋的部分；腹部钢筋要求等直径、等间距，每排不少于 4 根，
  换算成面积 Asw、高 hsw 的钢带；按平截面假定写出的 Nsw、Msw 再用直线和二次曲线拟合（取 βc = fsw/(Es εcu) ≈ 0.4，β = 0.8），
  得到式（5.3.7-3）、（5.3.7-4）。Nsw 为负表示受拉，Msw 为负表示与 Nd e 同向。

**程序**：`jtg.eccentric(..., method="web")`（`members._eccentric_web`）。

- As、A′s 取边排钢筋（第 10 节），其余钢筋都算 Asw；腹部钢筋至少 4 个不同深度（程序约定："每排不少于 4 根"读作每侧沿腹高不少于 4 根；
  截面里同一深度的两侧钢筋合为一个点），否则报错；间距不均匀（最大间距超过最小的 1.5 倍）时给出提示。
- h0 到 As 合力点，a′s 到 A′s 合力点，hsw = h0 − a′s；e 从毛截面重心算起（同 5.9 第 1 步），荷载点到 As 的距离 = e + h0 − zg。
- 混凝土受压区按截面实际形状取 x 以上的部分（x ≤ h，即注中 ξ ≤ h/h0），所以 T 形 x ≤ h′f、I 形 x > h − hf、箱形都自动包括。
- fsw 取 min(fsd, f′sd)（程序约定：公式里受拉、受压用同一个 fsw；只有 HRB500 两者不同，取 400 MPa）。
- (ξ − β)/(βω) 下限取 −1（程序约定）：此时中和轴在腹部钢筋以上，腹部钢筋全部受拉，Nsw = −fsw Asw、Msw = −0.5 fsw Asw hsw；
  公式外推到更小的 ξ 会超过钢筋的总拉力。只在 x < βa′s 时起作用，通常已进入 5.3.7-5 分支。
- 大偏心、x < 2a′s 且荷载在 A′s 以外时用式（5.3.7-5）。小偏心（ξ > ξb）时另按 5.3.4-4 / 5.3.5-3、-4 验算反向破坏（不计腹部钢筋，偏安全；
  5.3.7 本身没有反向破坏公式，程序约定）。
- 只用于钢筋混凝土；圆形截面报错。`method="auto"` 不会自动选用本条（仍是逐根钢筋的统一算法）。
- 式（5.3.7-3）、（5.3.7-4）恰好等于刚塑性钢带（中和轴 x/β 以上 fsw 受压、以下 fsw 受拉）的合力和对 As 的力矩，即条文说明中大偏心
  表达式取 βc → 0 的极限；测试中逐点积分验证到 10⁻⁴。
- 与统一算法（逐根按 5.1.5）的比较：带侧面钢筋的 1200×2000 矩形墩、带腹板钢筋的箱形墩，大、小偏心共 9 个工况，相差 +0.1%～+1.5%
  （5.3.7 略高，刚塑性假定忽略了中和轴附近钢筋未屈服）。

## 5.12 双向偏心受压（5.3.11，p40；条文说明 p183–184）

截面有两个互相垂直的对称轴的钢筋混凝土双向偏心受压构件：

$$\gamma_0 N_d \le \frac{1}{\dfrac{1}{N_{ux}} + \dfrac{1}{N_{uy}} - \dfrac{1}{N_{u0}}} \qquad (5.3.11)$$

- Nu0：按式（5.3.1）取等号、计入全部纵筋、不计稳定系数 φ 的轴心受压承载力，即 0.9(fcd A + f′sd A′s)。
- Nux：轴力作用在 x 轴上、偏心距取 ηx e0x、计入全部纵筋的偏心受压承载力；纵筋布置在截面上下两边时按 5.3.4 或 5.3.5，
  沿腹部均匀布置时按 5.3.7；ηx 按 5.3.9。Nuy 同理（y 轴、ηy e0y）。图 5.3.11 中 X 轴沿截面高 h，Y 轴沿宽 b。
- 条文说明（p183–184）：双向偏压的破坏形态与单向相似，但受压区形状复杂；本式是尼克丁（N. V. Nikitin）按材料力学方法由单向偏压推得的，
  只用于截面承载力复核。

**程序**：`jtg.biaxial(sec_x, sec_y, Nd, Mdx, Mdy, *, l0x=None, l0y=None, gamma0=1.0, method="auto")`；截面用
`jtg.rect_biaxial(b, h, *, bars=[(u, v, 直径)], layout=(nb, nh, d, 保护层), concrete=, steel=)` 生成两个方向的 `RCSection`：
sec_x 深 h、宽 b（正弯矩压上边），sec_y 深 b、宽 h（正弯矩压左边）；u 从左边量、v 从上边量；layout 为每条宽 b 的边 nb 根、
每条高 h 的边 nh 根（含角筋）。

- Mdx = Nd e0x（偏心距沿 X，即 sec_x 的深度方向），Mdy 同理。Nux、Nuy 由 `jtg.eccentric` 算（含 η、5.3.9 的 e0 下限、各自的 l0、
  所选 method），Nu0 按 5.3.1（含配筋率超过 3% 时扣除纵筋面积）。
- 两个截面必须面积、钢筋总量相同，且各自对中轴对称（混凝土和钢筋），否则报错。
- e0 下限：按 5.3.9 字面，两个方向各自不小于 max(20 mm, 该方向尺寸/30)。所以一个弯矩为零时，本式在那个方向仍按最小偏心距计，
  比单向验算（5.3.4～5.3.10）略保守，程序给出提示。另外 Nu0 含 0.9 而 Nux、Nuy 不含，单向极限下本式不严格退化为 Nux
  （测试中相差 3% 以内）。
- 圆形、空心圆截面（程序约定）：对任何轴都对称，用合成弯矩 √(Mdx² + Mdy²) 按单向 `jtg.eccentric` 验算，l0 取 l0x、l0y 的较大者；
  不需要 sec_y。
- 9.1.12 的最小配筋在两个方向的单向验算中各查一次（每一侧 0.2% 两个方向都查）。
- 预应力截面报错（5.3.11 是钢筋混凝土条文）。
- 校核：与双向应变协调解（中和轴任意倾角，混凝土取受压最远点起 βxc 范围内的 fcd，钢筋按 5.1.5，求轴力恰好作用在 (ηx e0x, ηy e0y) 的
  极限状态）比较，800×1200、C40、20Φ28 的 4 个工况相差 −0.7%～+4.8%（本式在轴力较小时略偏高）。

## 5.13 受压构件计算长度（附录 E，p131–132；条文说明 p256–258）

**E.0.1**

$$l_0 = k l \qquad (\text{E.0.1})$$

k 为计算长度换算系数，可按经验或 E.0.2、E.0.3 取；两端固定 0.5，一端固定一端不移动的铰 0.7，两端不移动的铰 1.0，一端固定一端自由 2.0；
l 为构件支点间长度。

**E.0.2** 一端固定、另一端有转动和水平弹性约束（图 E.0.2）：

$$k = 0.5\exp\left[\frac{0.35}{1 + 0.6 k_\theta} + \frac{0.7}{1 + 0.01 k_F^2} + \frac{0.35}{(1 + 0.75 k_\theta)(1 + 1.15 k_F)}\right] \qquad (\text{E.0.2-1})$$

$$k_\theta = K_\theta \frac{l}{EI} \qquad (\text{E.0.2-2})$$

$$k_F = K_F \frac{l^3}{EI} \qquad (\text{E.0.2-3})$$

Kθ、KF：弹性约束端的转动约束刚度、水平约束刚度；kθ、kF：相对刚度系数；EI：构件截面抗弯刚度。

**E.0.3** 一端固定、另一端只有水平弹性约束（图 E.0.3）：

$$k = 2 - \frac{1.3 k_F^{1.5}}{9.5 + k_F^{1.5}} \qquad (\text{E.0.3})$$

条文说明（p256–258）：把端部约束理想化为转动、横向弹簧，由转角位移方程和稳定函数写出失稳的行列式条件（式 E-8～E-14）；底端固定时化为
式（E-15），数值求解后拟合成式（E-16），即 E.0.2-1；kθ = 0 时化为 tan(π/k) = π/k − (π/k)³/kF（式 E-17），拟合成式（E-18），即 E.0.3。

**程序**：`jtg.length_factor(*, ends=None, k_theta=None, k_F=None)` → k；`jtg.effective_length(l, *, ends=None, k=None, K_theta=None, K_F=None, EI=None)`
→ l0 = k l（mm；Kθ 用 N·mm/rad，KF 用 N/mm，EI 用 N·mm²）。`ends` 取 "fixed-fixed"、"fixed-pinned"、"pinned-pinned"、"fixed-free"；
`K_theta` 为 None 或 0 时按 E.0.3，否则 E.0.2-1；刚性约束可传 `math.inf`。结果作为 `l0` 传给 `jtg.axial`、`jtg.eccentric`、`jtg.axial_spiral`、
`jtg.biaxial`。EI 的取法（毛截面还是开裂截面）规范未定，由使用者给出。

校核：与弹性约束柱的屈曲特征值（Hermite 梁单元 + 几何刚度，40 个单元；kθ = 0 时与式 E-17 一致到 10⁻⁶）比较：E.0.2-1 在 kθ 0.1～∞、kF 0～∞ 的
范围内为 −7.4%～+5.7%（测试网格内 8% 以内）；E.0.3 为 0～+9.3%，从不小于精确值（偏安全）；端部极限 2、0.7、1、0.5 都能复现。

## 20 受拉构件（5.4，p40–42；条文说明 p184）

### 20.1 轴心受拉（5.4.1，p40–41）

$$\gamma_0 N_d \le N_{ud} = f_{sd} A_s + f_{pd} A_p \qquad (5.4.1)$$

As、Ap 为全部普通钢筋、预应力钢筋的截面面积。

### 20.2 矩形截面偏心受拉（5.4.2，p41）

小偏心受拉（轴力作用在 As 与 Ap 的合力点和 A′s 与 A′p 的合力点之间，图 5.4.2a）：

$$\gamma_0 N_d e \le f_{sd} A'_s (h_0 - a'_s) + f_{pd} A'_p (h_0 - a'_p) \qquad (5.4.2\text{-}1)$$

$$\gamma_0 N_d e' \le f_{sd} A_s (h'_0 - a_s) + f_{pd} A_p (h'_0 - a_p) \qquad (5.4.2\text{-}2)$$

大偏心受拉（轴力不在上述两个合力点之间，图 5.4.2b）：

$$\gamma_0 N_d \le f_{sd} A_s + f_{pd} A_p - f'_{sd} A'_s - (f'_{pd} - \sigma'_{p0}) A'_p - f_{cd} b x \qquad (5.4.2\text{-}3)$$

$$\gamma_0 N_d e \le f_{cd} b x \left(h_0 - \frac{x}{2}\right) + f'_{sd} A'_s (h_0 - a'_s) + (f'_{pd} - \sigma'_{p0}) A'_p (h_0 - a'_p) \qquad (5.4.2\text{-}4)$$

- e、e′：轴力作用点到 As、Ap 合力点和到 A′s、A′p 合力点的距离；h0、h′0：截面两边到对面钢筋合力点的距离（图 5.4.2）。
- 大偏心时 x 要满足式（5.2.2-3）（x ≤ ξb h0）；计入受压钢筋时还要满足式（5.2.2-4）或（5.2.2-5）（x ≥ 2a′ 或 2a′s）；不满足时按式（5.2.4-1）、
  （5.2.4-2）计算，其中 Md 换成 Nd e′、Nd e′s。

### 20.3 对称配筋矩形截面双向偏心受拉（5.4.3，p41–42）

$$\gamma_0 N_d \le \frac{1}{\dfrac{1}{N_{ud}} + \sqrt{\left(\dfrac{e_{0x}}{M_{ux}}\right)^2 + \left(\dfrac{e_{0y}}{M_{uy}}\right)^2}} \qquad (5.4.3)$$

Nud 按式（5.4.1）；e0x、e0y 为轴向拉力对通过截面重心的 y 轴、x 轴的偏心距；Mux、Muy 为 x、y 方向的正截面抗弯承载力，按 5.2 节。

### 20.4 沿周边均匀配筋圆形截面偏心受拉（5.4.4，p42）

$$\gamma_0 N_d \le \frac{1}{\dfrac{1}{N_{ud}} + \dfrac{e_0}{M_{ud}}} \qquad (5.4.4)$$

Nud 按式（5.4.1）；e0 为轴向拉力对截面重心的偏心距；Mud 为取 Nud = 0（无轴力）按 5.3.8 算得的正截面抗弯承载力。

条文说明（p184）：5.4.3、5.4.4 参照 GB 50010；圆形截面偏心受拉的承载力基本符合 Nd/Nud + Md/Mud = 1 的规律且略偏安全，改写即得式（5.4.4）；
试验表明它也适用于对称配筋矩形截面的双向偏心受拉，把 e0/Mud 换成 √((e0x/Mux)² + (e0y/Muy)²) 即得式（5.4.3）。

### 20.5 受拉构件的最小配筋（9.1.12，p101）

受拉一侧的配筋百分率不小于 45 ftd/fsd，同时不小于 0.2；轴心受拉、小偏心受拉按毛截面面积计算，大偏心受拉按 100As/(b h0)（b 为腹板宽，
箱梁取各腹板宽之和）；大偏心受拉构件在受压区配有按计算需要的受压钢筋时，其配筋百分率按毛截面面积不小于 0.2。

### 20.6 受拉构件的程序做法

程序：`jtg.tension(section, Nd, Md=0.0, *, gamma0=1.0)`；`jtg.biaxial_tension(sec_x, sec_y, Nd, Mdx, Mdy, *, gamma0=1.0)`。

1. Nd 为拉力（kN，> 0），Md 为同时作用的弯矩（kN·m），e0 = |Md|/Nd；正弯矩时拉力作用点在毛截面重心以下（靠近 As），负弯矩时截面翻转。
   受拉构件不乘 η。
2. Md = 0：式（5.4.1），所有普通钢筋按 fsd、预应力钢筋按 fpd。
3. 圆形、空心圆：式（5.4.4）。实心圆且不少于 8 根时 Mud 按式（5.3.8）取 N = 0 解出 α；否则用统一算法的纯弯承载力（程序约定）。
4. 其他截面：As、Ap、A′s、A′p 取边排（第 10 节），合力点按 fsd、fpd 加权。荷载在两个合力点之间为小偏心：
   Nu = min(M_As / e, M_A′s / e′)，M_As 为其余全部钢筋（按 fsd、fpd）对 As、Ap 合力点的力矩，M_A′s 同理。对只有上下两排钢筋的矩形截面，
   这正是式（5.4.2-1）、（5.4.2-2）；侧面、腹部钢筋也计入（程序约定：受拉时这些钢筋同样屈服，计入后 e0 → 0 时连续地回到式 5.4.1）。
5. 荷载在 As、Ap 合力点以外为大偏心：用统一算法（`RCSection.forces`）求 x，使截面合力为拉力且作用在荷载点上；矩形截面即式（5.4.2-3）、
   （5.4.2-4），T、I、箱形截面按实际受压区形状（式 5.4.2 写的是矩形，推广属程序约定）。x > ξb h0 判为不满足（5.2.2-3）。x < 2a′ 时按式（5.2.4）
   对受压钢筋合力点取矩（Md 换成 Nd e′）；与受弯一样（3.6 节），也算去掉受压边排钢筋的截面（其自身 x ≤ ξb h0 时），两者取大。
6. 9.1.12（钢筋混凝土）：轴心受拉、小偏心受拉时上下两侧边排钢筋都按毛截面面积查（两侧都受拉）；大偏心受拉查 As/(b h0)；若去掉受压边排钢筋后
   抗力不足 γ0Nd（即受压钢筋为计算所需），再查受压钢筋不少于毛截面的 0.2%。圆形截面受拉以一半纵筋作"一侧"（程序约定）。预应力截面不查。
7. `biaxial_tension`：只用于对称配筋矩形（否则报错）；Mux、Muy 取 `jtg.flexure` 的抗弯承载力；最小配筋取两个方向 `jtg.tension` 的结果。
   圆形截面用 e0 = √(e0x² + e0y²) 按式（5.4.4）。

校核（`tests/test_members.py`）：式（5.4.1）、（5.4.2-1）～（5.4.2-4）手算；e0 → 0 时回到 5.4.1，e0 → ∞ 时 Nu·e0 → `jtg.flexure` 的 Mu；
对称配筋矩形截面的小偏心结果恰好等于线性相关式 1/(1/Nud + e0/Mu)（Mu = fsd As (h0 − a′)），即条文说明由 5.4.4 推 5.4.3 的依据；
圆形截面式（5.4.4）不大于统一算法求出的偏心受拉承载力（条文说明"略偏于安全"）；Mud（5.3.8，N = 0）与统一算法的纯弯承载力相差 2% 以内。
