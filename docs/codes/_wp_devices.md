程序：`femotion.codes.jtg.devices`（顶层导出 `jtg.hinge_compression`、`jtg.hinge_transverse`、`jtg.hinge_contact_width`、`jtg.Laminated`、

### 26.1 混凝土铰的受压（8.6.1，p90–91；条文说明 p221–222）

线接触的圆柱形铰，受压面的抗压承载力宜满足：

$$\gamma_0 F_{hd} \le \frac{7.14\,(\eta_s \beta f_{cd})^2\, l}{E_c\left(\dfrac{1}{r_1} - \dfrac{1}{r_2}\right)} \qquad (8.6.1\text{-}1)$$

$$\beta = \sqrt{\frac{A_b}{b\,l}} \qquad (8.6.1\text{-}2)$$

压力传递面的宽度 b（图 8.6.1）：

$$b = 2.74\sqrt{\frac{\gamma_0 F_{hd}}{E_c\left(\dfrac{1}{r_1} - \dfrac{1}{r_2}\right) l}} \qquad (8.6.1\text{-}3)$$

| 符号 | 含义 |
|---|---|
| Fhd | 作用在铰受压面上的压力设计值 |
| fcd | 混凝土轴心抗压强度设计值 |
| Ab | 局部受压的计算底面积，按图 5.7.1 |
| ηs | 混凝土局部承压修正系数，按 5.7.1 |
| l | 圆柱形铰的长度 |
| Ec | 混凝土弹性模量 |
| r1、r2 | 上、下圆柱体的半径；上圆柱体与平面接触时取 1/r2 = 0 |
| γ0 | 结构重要性系数 |

图 8.6.1：上块的凸面（半径 r1）坐在下块的凹面（半径 r2）上，铰宽 a、铰高 h（上、下块各一个 h），接触带宽 b。

条文说明（p221–222）的推导：赫兹公式（《机械设计手册》）给线接触最大压应力 σmax = 0.564 √[(P/l)(1/r1 − 1/r2) / ((1 − ν1²)/E1 +
(1 − ν2²)/E2)]（式 8-9）；E1 = E2 = Ec、按 3.1.6 取 νc = 0.2，得 σmax = 0.407 √[(P Ec / l)(1/r1 − 1/r2)]（式 8-10），平均压力
fcm = (π/4) σmax = 0.32 √[…]（式 8-11）。承载能力极限状态下不一定符合赫兹公式，故仍按弹性状态、容许应力定承载力：参照 JTJ 023—85 和
1975 年规范，轴心抗压容许应力取 0.75 fcd，铰的压力取 P = γ0Fhd/1.3，计入 β、ηs 后 fcm = 0.75 β ηs fcd，代入式（8-11）解出式（8-12）
即式（8.6.1-1）；接触宽 b = P/(fcm l) 即式（8-13）、（8.6.1-3）。

**程序**：`jtg.hinge_contact_width(Fhd, *, Ec, r1, r2=inf, l, gamma0=1.0)` → b（mm）；
`jtg.hinge_compression(concrete, Fhd, *, l, r1, r2=inf, a=None, Ab=None, gamma0=1.0)` → `Check`（demand = γ0Fhd，resistance = 式 8.6.1-1，
details 给出 b、Ab、β、ηs、fcd、Ec 和 P = γ0Fhd/1.3 时的平均压力）。程序约定：
- **Ab**：给了铰宽 a 时按图 5.7.1 下排（条带荷载）取：接触带 b × l 沿铰长 l 通长、居铰宽 a 的中间，c = (a − b)/2，Ab = (b + 2 min(b, c)) l
  （`bearing_base_area(b, l, cx=c, cy=0)`）；沿 l 方向通长，不再外扩。其他布置直接传 `Ab`。b ≥ a 时列入不满足（`failed`）。
- **r2**：r2 = ∞ 表示平面（1/r2 = 0）；要求 r2 > r1（凸面坐在更大的凹面里）。两个凸面接触（曲率相加）规范的式子不适用，报错。
- 上、下块为同一种混凝土（条文说明 E1 = E2 = Ec），Ec、fcd、ηs 都取这一强度等级（表 3.1.4、3.1.5，5.7.1）。
- 9.8.3 的构造（凸面半径、C30）写进 `warnings`，见 26.13。

### 26.2 混凝土铰的横向抗拉（8.6.2，p91；条文说明 p222–223）

$$\gamma_0 F_{hd} \le \frac{h}{0.425\,(a - b)}\, f_{sd} A_s \qquad (8.6.2)$$

| 符号 | 含义 |
|---|---|
| fsd | 铰内横向钢筋的抗拉强度设计值 |
| a | 铰的宽度 |
| h | 铰的高度，取 a 的 0.80～1.25 倍 |
| b | 铰的压力传递面宽度，按式（8.6.1-3） |
| As | 铰的横向抗拉钢筋截面面积 |

铰的侧向（沿铰长方向）可按横向钢筋截面面积的 0.4 倍配筋。

条文说明（p222–223）：式子参照《公路设计手册·拱桥（上册）》（1978 年版），用 E. Mörsch 的铰内横向拉力 z = 1.5 (a − b) P / (4h)（式 8-14），
各级钢筋容许应力平均取 0.68 fsd、P = γ0Fhd/1.3，由 0.68 fsd As ≥ z 解出式（8-15）。1977 年北京市政二公司等四单位的试验：横向拉力约为
受压面压力的 0.25～0.3 倍，侧向拉力约 0.1 倍，两者之比 2.5～3.0，故侧向钢筋取横向的 0.4 倍。h = 0.8～1.25 a 沿用苏联 CH 200—62 第 329 条，
20 世纪 50 年代起公路、铁路部门一直采用。

**程序**：`jtg.hinge_transverse(Fhd, *, a, h, b, As, steel="HRB400", gamma0=1.0, As_side=None)` → `Check`。b 用 `hinge_contact_width` 或
`hinge_compression(...).details["b"]`。程序约定：
- h 不在 [0.80a, 1.25a]（闭区间）时列入不满足（`failed`）：式子按这一高宽比推得，属于公式的适用条件。
- fsd 取钢筋的抗拉设计值，**不**按表 3.2.3-1 注 1 限到 330 MPa（该注只针对抗剪、抗扭、抗冲切的横向钢筋）。
- 侧向钢筋：details["As_side"] = 0.4 As；给了 `As_side` 且小于 0.4 As 时写进 `warnings`（原文用"可"，属构造建议）。
- details["z"]：式（8-14）的横向拉力（P = γ0Fhd/1.3），供核对。

### 26.3 支座的一般要求（8.7.1、8.7.2，p91；条文说明 p223）

8.7.1 桥梁支座：
1. 能把上部结构的自重、汽车荷载等竖向作用传给下部结构，并在风、地震等水平荷载作用下保证上部结构安全。
2. 支座类型和规格按上、下部结构形式、支座反力和水平力设计值、支座处位移量确定。
3. 支座反力设计值 Rck 按竖向荷载标准值组合计算，汽车荷载计入冲击系数。
4. 支座水平力设计值按水平作用标准值组合计算。
5. 计算支座处梁的相对位移时考虑：1）温度变化、汽车制动力等；2）梁的挠曲；3）施加预应力引起的主梁位移；4）混凝土收缩徐变；
   5）地震等偶然作用。

8.7.2 板式橡胶支座的基本设计数据、产品分类、技术要求、试验方法、检验规则按现行 JT/T 4。条文说明（p223）：数据来自 1992 年编制 JT/T 4—1993
时的试验（抗压弹性模量 147 个试件、抗剪弹性模量 105 对、转角 61 对、四氟滑板与不锈钢板摩擦系数 24 个、破坏 51 个），2003 年修订时又做了
抗压弹性模量 42 块、抗剪弹性模量 30 块，并参考了 AASHTO LRFD、CEN/TC 167 N185、BS 5400。条文说明 8.7.1 提醒：设计应考虑支座安装时的温度
和预应力张拉等施工因素，否则成桥后支座受力和变形易"超量"，剪切变形过大。

**程序**：第 3、4 款的组合用 `jtg.characteristic_combination`（D60 4.1.8，全部分项系数为 1）。第 5 款见 26.10（`jtg.movements`）：1）～4）
都有对应的项；5）地震等偶然作用不含，由使用者另算。

### 26.5 板式橡胶支座的选配（8.7.3，p92–93；条文说明 p223–224）

**1 有效承压面积**

$$A_e \ge \frac{R_{ck}}{\sigma_c} \qquad (8.7.3\text{-}1)$$

Ae：支座有效承压面积（承压加劲钢板面积）；Rck：支座反力设计值，汽车荷载计入冲击系数；σc：使用阶段支座平均压应力限值，按 JT/T 4。

**2 橡胶层总厚度**

1）满足剪切变形：

$$t_e \ge 2\Delta_l\ \text{（不计制动力）} \qquad (8.7.3\text{-}2)$$

$$t_e \ge 1.43\Delta_l\ \text{（计入制动力）} \qquad (8.7.3\text{-}3)$$

支座在横桥向平行于墩台帽或盖梁顶横坡设置时：

$$t_e \ge 2\sqrt{\Delta_l^2 + \Delta_t^2}\ \text{（不计制动力）} \qquad (8.7.3\text{-}4)$$

$$t_e \ge 1.43\sqrt{\Delta_l^2 + \Delta_t^2}\ \text{（计入制动力）} \qquad (8.7.3\text{-}5)$$

- te：支座橡胶层总厚度。
- Δl：上部结构温度变化、混凝土收缩和徐变等作用标准值引起的支座剪切变形，加上纵向力标准值（计入制动力标准值）产生的剪切变形，以及支座直接
  设置于不大于 1% 纵坡的梁底面下时，支座反力设计值顺纵坡方向的分力产生的剪切变形。
- Δt：支座在横桥向平行于不大于 2% 的墩台帽或盖梁顶横坡上设置时，支座反力设计值平行于横坡方向的分力产生的剪切变形。

2）保证受压稳定：

$$\frac{l_a}{10} \le t_e \le \frac{l_a}{5}\ \text{（矩形支座）} \qquad (8.7.3\text{-}6)$$

$$\frac{d}{10} \le t_e \le \frac{d}{5}\ \text{（圆形支座）} \qquad (8.7.3\text{-}7)$$

la：矩形支座短边尺寸；d：圆形支座直径。

**3 竖向平均压缩变形**

$$\delta_{c,m} = \frac{R_{ck} t_e}{A_e E_e} + \frac{R_{ck} t_e}{A_e E_b} \qquad (8.7.3\text{-}8)$$

$$\theta\,\frac{l_a}{2} \le \delta_{c,m} \le 0.07\,t_e \qquad (8.7.3\text{-}9)$$

δc,m：支座竖向平均压缩变形；Ee：支座抗压弹性模量，按 JT/T 4；Eb：橡胶弹性体体积模量，按 JT/T 4；la：矩形支座短边尺寸或圆形支座直径；
θ：上部结构挠曲在支座顶面引起的倾角，以及支座直接设置于不大于 1% 纵坡的梁底面下时在支座顶面引起的纵坡坡角（rad）。

**4 加劲钢板**（最小厚度不小于 2 mm）

$$t_s \ge \frac{K_p R_{ck}(t_{es,u} + t_{es,l})}{A_e \sigma_s} \qquad (8.7.3\text{-}10)$$

ts：加劲钢板厚度；Kp：应力校正系数，取 1.3；tes,u、tes,l：一块加劲钢板上、下的橡胶层厚度；σs：加劲钢板轴向拉应力限值，可取钢材屈服
强度的 0.65 倍。加劲钢板与支座边缘的最小距离不小于 5 mm，上、下保护层厚度不小于 2.5 mm。

条文说明（p223–224）：各项按正常使用极限状态、使用阶段计算（AASHTO LRFD 14.7.5.3.2 也以平均压应力验算抗压）。有效承压面积限于加劲钢板
面积。Δl 中温度、收缩徐变引起的部分可直接由上部结构长度变化求得；纵向力和纵坡分力引起的部分，先算出分给支座的剪力，再按
tanα = Δl/te = Fk/(Ag Ge) 求剪切变形（图 8-16）；计算时可取单个支座。横坡上的支座只有横向剪切变形、没有不均匀压缩，算法同纵向。
式（8.7.3-6）、（8.7.3-7）兼顾行车平稳（不能太厚）和剪切变形、转角（不能太薄）。式（8.7.3-9）左边保证转角时不脱空，右边限制压缩
变形以免影响稳定（图 8-17）。Eb 取 2000 MPa（JTJ 023—85 未计）。Kp 欧洲标准取 1.3、国际铁路联盟取 2，本规范取 1.3。

**程序**：`jtg.Laminated(la, lb=None, *, t1, n, ts, cover=2.5, edge=5.0, G=1.0, E=None, Eb=2000.0, rubber=None, circle=False)`：
矩形 la × lb（la 为短边，la > lb 报错）或圆形（`circle=True`，直径 la）；n 层中间橡胶片 t1，n + 1 块加劲钢板 ts；属性 `l0a`、`l0b`
（钢板尺寸 = 支座尺寸 − 2 edge）、`Ae`（钢板面积）、`Ag`（毛面积）、`te`、`S`、`Ee`、`k = Ge Ag / te`（kN/mm）、`height`。
`jtg.laminated_bearing(b, Rck, *, sigma_c, dl, fy_plate, Fbk=None, dl_brake=None, slope=0.0, slope_t=0.0, theta=0.0)` → `list[Check]`
（面积、不计制动力的剪切、计入制动力的剪切（给了 `Fbk` 或 `dl_brake` 时）、稳定、压缩变形、加劲钢板）。程序约定：
- **te** 默认 n t1 + 2 × 保护层：上、下保护层与中间橡胶片一起剪切（物理上如此）；实际总厚度不同时传 `rubber`。
- **Δl**：`dl` 为不含制动力的剪切变形（温度、收缩徐变等，一般取 `Movements.bearing_shear()`，见 26.10），程序再加上纵坡分力的剪切变形
  Rck sin(arctan i)/k（`devices.slope_shear`）；制动力部分为 `dl_brake`，或由分给本支座的制动力 Fbk 算 Fbk te/(Ge Ag)（与 8.8.2 第 4 款同式）。
  横坡 Δt = Rck sin(arctan it)/k。纵坡 > 1%、横坡 > 2% 超出本条的前提，列入不满足（应调平，9.7.4）。
- **θ** = `theta` + arctan(纵坡)。la 取短边或直径（原文如此）。
- **tes,u + tes,l**：取中间钢板（上、下各一层 t1，即 2t1）；只有一层中间橡胶片（n = 1）时取 t1 + 保护层厚度。
- 加劲钢板 < 2 mm、边距 < 5 mm、保护层 < 2.5 mm 写进 `warnings`（构造），不改变 `ok`；式（8.7.3-10）本身是计算，计入 `ok`。
- S 不在 5～12：Ee 用默认的 5.4 G S² 时，公式不适用，列入压缩变形一项的不满足；使用者给了 `E` 时只写 `warnings`。
- Rck ≥ 5000 kN 时提示 JT/T 4—2019 只适用于 5000 kN 以下的支座（`notes`）。
- 校核：te ≥ 2Δl 与 tanα = Δl/te ≤ 0.5 等价；te ≥ 1.43Δl 对应 tanα ≤ 1/1.43 = 0.699，比 JT/T 4—2019 第 5.4.5 条的 0.7 略严（测试覆盖两侧）。

### 26.6 板式橡胶支座的抗滑稳定（8.7.4，p93；条文说明 p224）

$$\mu R_{Gk} \ge 1.4\, G_e A_g \frac{\Delta_l}{t_e}\ \text{（不计汽车制动力）} \qquad (8.7.4\text{-}1)$$

$$\mu R_{ck} \ge 1.4\, G_e A_g \frac{\Delta_l}{t_e} + F_{bk}\ \text{（计入汽车制动力）} \qquad (8.7.4\text{-}2)$$

RGk：结构自重引起的支座反力；Rck：结构自重标准值和 0.5 倍汽车荷载标准值（计入冲击系数）引起的支座反力；μ：支座与接触面的摩擦系数，
按 JT/T 4；Ge：支座剪变模量，按 JT/T 4；Δl：见 8.7.3，但不含汽车制动力引起的剪切变形；Fbk：汽车荷载引起的制动力标准值；Ag：支座平面
毛面积。条文说明（p224）：沿用 JTJ 023—85，按使用阶段计算；汽车荷载取标准值的 0.5 倍，是试算后取较小反力的结果。

**程序**：`jtg.laminated_sliding(b, *, mu, RGk, dl, RQk=0.0, Fbk=None)` → `list[Check]`；RQk 为汽车荷载（计入冲击）引起的反力标准值，
Rck = RGk + 0.5 RQk；给了 Fbk（分给本支座的制动力）才算式（8.7.4-2）。`dl` 与 `laminated_bearing` 的 Δl 相同（不含制动力；有纵坡时
加 `slope_shear`）。

### 26.7 聚四氟乙烯滑板支座（8.7.5，p94；条文说明 p224）

$$\mu_f R_{Gk} \le G_e A_g \tan\alpha\ \text{（不计汽车制动力）} \qquad (8.7.5\text{-}1)$$

$$\mu_f R_{ck} \le G_e A_g \tan\alpha\ \text{（计入汽车制动力）} \qquad (8.7.5\text{-}2)$$

μf：聚四氟乙烯与不锈钢板的摩擦系数，按 JT/T 4；tanα：橡胶支座剪切角正切值的限值，按 JT/T 4；Rck：结构自重标准值和汽车荷载标准值
（计入冲击系数）引起的支座反力；Ag：支座平面毛面积。条文说明（p224）：滑板支座的摩擦力不应使支座内橡胶层的剪切变形超过容许值，
右边 Ge Ag tanα = Fk 是 tanα 限值对应的容许水平力，控制因素是 Ag。

**程序**：`jtg.ptfe_sliding(b, *, mu_f, RGk, RQk=None, tan_alpha=(0.5, 0.7))` → `list[Check]`；tanα 按 JT/T 4—2019 第 5.4.5 条：
式（8.7.5-1）取不计制动力的 0.5，式（8.7.5-2）取计入制动力的 0.7；给了 RQk 才算式（8.7.5-2），Rck = RGk + RQk。

### 26.8 盆式橡胶支座、球型支座（8.7.6，p94）

定型生产的盆式橡胶支座、球型支座分别符合 JT/T 391—2009《公路桥梁盆式橡胶支座》、GB/T 17955—2009《桥梁球型支座》。3362 没有给计算公式，
程序不做（按产品标准选型）。条文说明 8.7.1：球型支座适应大转角但转动刚度小，弯桥为增大主梁抗扭刚度一般用盆式支座。

### 26.9 伸缩装置（8.8，p94–96；条文说明 p224–225）

8.8.1（不做数值）：材料和成品按 JT/T 327—2016《公路桥梁伸缩装置通用技术条件》；定型产品按桥位气温和施工季节选安装温度，按 8.8.2 算接缝处
梁体的伸长和缩短（闭口量、开口量）选型；自行设计时承受汽车荷载的钢构件要考虑冲击和重复作用引起的疲劳；图纸上要画出槽口尺寸、预埋件，
注明槽口填筑材料及强度等级、安装温度范围、伸缩装置的型号和最大最小工作宽度 Bmax、Bmin、安装宽度或出厂宽度、施工注意事项。

8.8.2 伸缩装置安装后的伸缩量可考虑下列因素：

1 温度变化：

$$\Delta l_t^{+} = \alpha_c\, l\,(T_{max} - T_{set,l}) \qquad (8.8.2\text{-}1)$$

$$\Delta l_t^{-} = \alpha_c\, l\,(T_{set,u} - T_{min}) \qquad (8.8.2\text{-}2)$$

Tmax、Tmin：当地最高、最低有效气温值，按 JTG D60—2015；Tset,u、Tset,l：预设安装温度范围的上限、下限；l：计算一个伸缩装置伸缩量所采用的
梁体长度，视桥梁长度分段及支座布置而定；αc：梁体混凝土线膨胀系数，αc = 0.000 01。

2 混凝土收缩：

$$\Delta l_s^{-} = \varepsilon_{cs}(t_u, t_0)\, l \qquad (8.8.2\text{-}3)$$

εcs(tu, t0)：伸缩装置安装完成时梁体混凝土龄期 t0 至收缩终了时龄期 tu 之间的收缩应变，按附录 C。

3 混凝土徐变：

$$\Delta l_c^{-} = \frac{\sigma_{pc}}{E_c}\,\phi(t_u, t_0)\, l \qquad (8.8.2\text{-}4)$$

σpc：预应力（扣除相应阶段损失）在截面重心处的法向压应力，简支梁可取跨中与 1/4 跨截面的平均值，连续梁、连续刚构可取若干代表截面的平均值；
Ec：梁体混凝土弹性模量，按表 3.1.5；φ(tu, t0)：安装完成时龄期 t0 至徐变终了时龄期 tu 的徐变系数，按附录 C。

4 制动力使板式橡胶支座剪切变形引起的开口量 Δlb⁻ 或闭口量 Δlb⁺：Δlb⁻ 或 Δlb⁺ = Fk te / (Ge Ag)，Fk 为分配给支座的汽车制动力标准值，
te 为支座橡胶层总厚度，Ge 为橡胶剪变模量（按 8.7.4），Ag 为支座平面毛面积。

5 按梁体的伸缩量选伸缩装置的型号：

$$C^{+} = \beta\,(\Delta l_t^{+} + \Delta l_b^{+}) \qquad (8.8.2\text{-}5)$$

$$C^{-} = \beta\,(\Delta l_t^{-} + \Delta l_s^{-} + \Delta l_c^{-} + \Delta l_b^{-}) \qquad (8.8.2\text{-}6)$$

$$C \ge C^{+} + C^{-} \qquad (8.8.2\text{-}7)$$

C⁺、C⁻：安装后的闭口量、开口量；C：伸缩装置的伸缩量；β：伸缩量增大系数，可取 1.2～1.4。
注：1 地震、风荷载、梁的挠度等其他影响伸缩量的因素，视具体情况考虑。2 施工安装温度超出设计规定的安装温度范围时，另行计算。

8.8.3 安装宽度（或出厂宽度）可按 8.8.2 的 C⁻、C⁺ 计算，在 [Bmin + (C − C⁻)] 与 (Bmin + C⁺) 之间（含两端）取用；C 为所选伸缩装置的伸缩量，
Bmin 为其最小工作宽度。

条文说明（p224–225）：影响伸缩量的还有梁端转角、日照引起的竖向和横向梯度温差、弯桥离心力引起的横向错动、斜桥端跨不等长等，故乘 β；
德国规范和《公路桥梁伸缩装置》一书取 1.3，本规范定为 1.2～1.4，按各种不利和有利因素选。收缩徐变在多年后完成，此时伸缩装置被拉开，
对闭口有富余，计算闭口量时不考虑，但可在定 β 时作为有利因素。制动力引起的伸缩与制动方向、连续长度、支座布置有关，按实际情况算最不利的
闭口量和开口量。柔性排架墩顶设板式橡胶支座时，墩与支座刚度串联，制动力引起的位移可用串联刚度计算（袁伦一《连续桥面简支梁墩台实例
（修订版）》）。

**程序**：`jtg.movements(l, *, T_set, T_max=None, T_min=None, zone=None, structure="concrete", south=False, alpha=1e-5, concrete=None,
RH=None, h=None, t0=None, tu=None, ts=3.0, method="table", fly_ash=None, eps_cs=None, phi=None, sigma_pc=0.0, elastic=False, brake=0.0,
theta=0.0, y=0.0)` → `Movements`（`t_plus`、`t_minus`、`shrinkage`、`creep`、`elastic`、`brake`、`rotation`，均为正值，mm；`closing(β)` 为
式 8.8.2-5，`opening(β)` 为式 8.8.2-6）；`jtg.expansion_joint(mv, C, *, beta=1.3, Bmin=None, kind=None)` → `Check`（C⁺ + C⁻ ≤ C，details 给出
C⁺、C⁻、各项和安装宽度）；`jtg.installation_width(C, Bmin, C_plus, C_minus)` → (Bmin + C⁺, Bmin + C − C⁻)；`devices.braking_movement(Fk, b)`
= Fk te/(Ge Ag)。程序约定：
- **温度**：Tmax、Tmin 直接给，或按 D60 表 4.3.12-2 由气候分区、结构类型取（`temperature.effective_temperature`，见 D60 文档第 7 节）。
  `T_set` 为 (下限, 上限) 或一个值；安装温度超出 [Tmin, Tmax] 或下限大于上限时报错。按注 2 复算实际安装温度：`T_set` 传实际温度。
- **αc**：默认 1×10⁻⁵（原文）；钢梁可传 `alpha=jtg.EXPANSION["steel"]`（D60 表 4.3.12-1），3362 本身不涉及钢梁。
- **收缩、徐变**：给了混凝土时按附录 C 算（`prestress.shrinkage_strain`、`creep_coefficient`，默认表法），t0 为安装（或支座就位）时的龄期；
  **tu 默认 t0 + 3650 d**：条文说明表 C-1、C-2 的"终极值"按 10 年延续期计算（表注 6）。也可直接给 `eps_cs`、`phi`。没给混凝土又没给
  εcs 时收缩取 0（`notes` 说明）。φ(tu, t0) 按原文以安装龄期 t0 为加载龄期（规范的简化），不另按张拉龄期扣除安装前已完成的徐变。
- **Ec** 取表 3.1.5（原文）。
- **制动力**：`brake`（mm）两边都加（原文开口、闭口取同一式）；一般为 `braking_movement(Fk, b)`；墩柔时用串联刚度算梁的位移
  （`devices.series`、`distribute`，见 26.10）。
- **β**：默认 1.3（条文说明所引德国规范和《公路桥梁伸缩装置》的取值）；小于 1.2 列入不满足；大于 1.4 偏于安全，只写 `notes`。
- 注 1 的地震、风、挠度等不计入。`kind`（9.7.7）不是"modular"（模数式）、"finger"（梳齿板式）、"seamless"（无缝式）时写进 `warnings`。
- 安装宽度：C ≥ C⁺ + C⁻ 时 details["installation"] 给出区间；`installation_width` 在 C < C⁺ + C⁻ 时报错（区间为空）。
  在区间内安装，闭口 C⁺ 后不小于 Bmin，开口 C⁻ 后不大于 Bmin + C（测试按此几何关系校核）。

### 26.10 支座处梁的位移（8.7.1 第 5 款）和刚度工具（程序约定）

`Movements` 同时用于支座：
- `elastic=True`：加上施加预应力引起的弹性压缩 σpc l / Ec（8.7.1 第 5 款 3），用于支座就位后才张拉的梁（如支架上现浇）；预制梁在就位前已张拉，
  不加。
- `theta`、`y`：梁端转角 θ 与截面重心到支座顶面的距离 y，位移 θ y（第 5 款 2）。重力荷载下梁端底面向跨外移动，与伸长同向，计入伸长一侧。
- `bearing_shear(braking=False)`：8.7.3 的 Δl 取伸长一侧（升温 + 转角）与缩短一侧（降温 + 收缩 + 徐变 + 弹性压缩）的较大值，两侧都从支座安装
  时算起（程序约定：两侧方向相反，不能相加）；`braking=True` 时再加 `brake`（`laminated_bearing` 另按 `Fbk` 计入制动力，一般不用）。
- 第 5 款 5）地震等偶然作用不含。

刚度工具（D60 4.3.5 第 3 款和条文说明 8.8.2 的做法，非规范条文）：
- `devices.series(*k)`：串联刚度 1/Σ(1/ki)，如支座与柔性墩。
- `devices.distribute(F, k)`：沿轴向视为刚体的一联梁上，水平力按刚度分配 Fi = F ki/Σk（D60 4.3.5 第 3 款）。
- `devices.stationary_point(x, k)`：均匀应变（温度、收缩、徐变）下的不动点 x0 = Σ ki xi / Σ ki（由 Σ ki (xi − x0) = 0）；各支座、
  伸缩缝的 l 取到 x0 的距离。

### 26.11 汽车荷载制动力（JTG D60—2015 4.3.5，p30；条文说明 p62）——建议并入 D60 文档

1. 制动力按同向行驶的汽车荷载（不计冲击力）计算，并按表 4.3.1-6，以使墩台产生最不利纵向力的加载长度进行纵向折减。
   1）一个设计车道的制动力标准值为车道荷载标准值在加载长度上总重力的 10%；公路—Ⅰ级不小于 165 kN，公路—Ⅱ级不小于 90 kN。
   2）同向行驶两车道为一个车道的 2 倍，三车道 2.34 倍，四车道 2.68 倍。
2. 着力点在桥面以上 1.2 m；计算墩台时可移到支座铰中心或支座底座面上；计算刚构桥、拱桥时可移到桥面上，但不计由此产生的竖向力和力矩。
3. 设板式橡胶支座的简支梁、连续桥面简支梁或连续梁排架式柔性墩台，按支座与墩台的抗推刚度集成分配和传递制动力；设板式橡胶支座的简支梁
   刚性墩台，按单跨两端板式橡胶支座的抗推刚度分配。
4. 设固定支座、活动支座（滚动或摆动支座、聚四氟乙烯板支座）的刚性墩台，按表 4.3.5；每个活动支座传递的制动力不大于其摩阻力，大于时按摩阻力计。

**表 4.3.5 刚性墩台各种支座传递的制动力**

| 桥梁墩台及支座类型 | | 应计的制动力 |
|---|---|---|
| 简支梁桥台 | 固定支座 | T1 |
| | 聚四氟乙烯板支座 | 0.30T1 |
| | 滚动（或摆动）支座 | 0.25T1 |
| 简支梁桥墩 | 两个固定支座 | T2 |
| | 一个固定支座，一个活动支座 | 注 |
| | 两个聚四氟乙烯板支座 | 0.30T2 |
| | 两个滚动（或摆动）支座 | 0.25T2 |
| 连续梁桥墩 | 固定支座 | T3 |
| | 聚四氟乙烯板支座 | 0.30T3 |
| | 滚动（或摆动）支座 | 0.25T3 |

符号：T1 为加载长度取计算跨径时的制动力；T2 为加载长度取相邻两跨计算跨径之和时的制动力；T3 为加载长度取一联长度时的制动力。
表注：固定支座按 T4、活动支座按 0.30T5（聚四氟乙烯板支座）或 0.25T5（滚动或摆动支座）计，T4、T5 分别为与固定支座、活动支座相应的单跨
跨径的制动力；桥墩承受的制动力为两者传递的制动力之和。

条文说明（p62）：沿用原规范，以加载长度内一行汽车车队总重力的百分数表示；10% 是名义值，许多情况下偏低，故设最小值 165 kN、90 kN；
多车道时乘车道数后再折减。刚性墩台制动力全部由固定支座传递，但活动支座有摩阻力，也传一部分；设板式橡胶支座的刚性墩台按跨径两端支座的
抗推刚度分配，两端相同时各 50%；柔性墩台用支座与墩台的集成刚度分配。

**程序**：`jtg.braking_force(L, lanes=1, grade="I", L0=None)` → kN（`actions.py`）。程序约定：
- 一个车道：max(0.1 (qk L + Pk) × 纵向折减系数(L), 165 或 90)；L 为加载长度（m），纵向折减按表 4.3.1-6 取 L；Pk 按表 4.3.1-2 由计算跨径
  L0 取，默认 L0 = L（加载长度跨过几跨时，使用者可传实际的计算跨径）。纵向折减只在 L > 150 m 时起作用，此时 10% 值已大于 165 kN（Ⅰ级）、
  90 kN（Ⅱ级），先折减还是先取最小值结果相同。
- 车道系数 1、2、2.34、2.68（`actions.BRAKING_LANE_FACTORS`）；超过四个同向车道原文没给，报错。条文说明"乘车道数后再折减"：2.34 = 3 × 0.78、
  2.68 = 4 × 0.67，即表 4.3.1-5 的横向折减（测试核对）。
- 第 3 款的分配用 `devices.distribute`、`series`；第 2 款的着力点、第 4 款和表 4.3.5 程序未实现（用于刚性墩台和固定、活动支座的墩台设计）。

### 26.15 原文问题

- **8.8.2 第 4 款（p95）**：正文"伸缩缝开口量 Δlb⁻ 或闭口量 Δlb⁻"，后一个应为 Δlb⁺（紧接的计算式写的是"Δlb⁻ 或 Δlb⁺ = Fk te/Ge Ag"，
  式 8.8.2-5 用的也是 Δlb⁺）。程序按开口、闭口各计一次。
- **条文说明 8.7.4（p224）**："本条公式（8.7.4-5）汽车荷载……取其标准值的 0.5 倍"，本条只有式（8.7.4-1）、（8.7.4-2），应为（8.7.4-2）。
- **常数的取整（不是印错）**：式（8.6.1-1）、（8.6.1-3）的 7.14、2.74 由条文说明式（8-11）取整的 0.32 推得；按赫兹解精确值 π/4 × 0.4072 =
  0.3198，两常数为 7.151、2.7426，规范值分别小 0.15%、0.1%（承载力略偏小，偏安全）。式（8.6.2）的 0.425 由 1.5/(4 × 1.3 × 0.68) = 0.4242
  向上取整，承载力比 Mörsch 推导值小 0.2%（偏安全）。式（8.7.3-3）的 1.43 对应 tanα ≤ 0.699，比 JT/T 4—2019 的 0.7 略严。
- **官方英文版**（只作定位，以中文为准）另有几处与中文不符：8.6.1 把 r1、r2 写成"diameters"（中文为半径）；8.7.5 第二式编号印成（8.7.4-2）；
